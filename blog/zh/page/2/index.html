    惡魔城開發史 第5回：一列上兩個編號，而唯一搜到的那一筆是另一台主機

    在PlayStation 2與PlayStation 3上，Kataban目錄把兩個商品編號用分號串在同一欄：BLJM60284;VT033-J1。前半照原樣搜就有效，後半回來HTTP 404。能用的編號每一個都只搆得到一個版本；而那一列自己的日文原名搜出來的唯一一筆，是另一個地區、另一台主機的光碟。系列開發史五部曲第5回（完結）。

    星之卡比開發史 第1回：Twinkle Popo如何成為《星之卡比》，以及它的商品編號DMG-KYJ

    卡比的第一款遊戲《星之卡比》於1992年4月27日在日本以Game Boy推出，商品編號DMG-KYJ。它原本是HAL研究所打算自行發行的Twinkle Popo，後來才由任天堂接手。本文談卡比在美國為什麼是白色的，以及為什麼用商品編號比用標題更快找到日版卡帶。系列開發史五部曲第1回。

    《空想科學世界》PC Engine 版：雜誌做出來的 RPG、會播賽璐珞動畫的光碟，以及為什麼只有一款

    哈德森1995年的 Super CD-ROM² RPG，編號 HCD5076，出自一本雜誌的媒體混合企劃（廣井王子×蘆田豐雄）。HuVIDEO 做了什麼、為什麼靠貿易賺錢，以及為什麼用片假名標題搜尋只會埋在動畫周邊裡。

    《Baku Baku Animal》登上 Game Gear：SEGA 的街機益智遊戲放進口袋

    Sega AM3 1995年的街機益智遊戲移植到四種家用主機，卻從未有續作。日版 Game Gear 卡帶編號 G-3378，四個來源的定價都是3,800日圓，Saturn 光碟也同名。駿河屋甚至把標題少登錄了一個詞，用完整名稱反而搜不到。

    《Royal Stone》：《Crystal Warriors》只在日本發售的 Game Gear 續作

    《Crystal Warriors》曾在歐美發售，1995年的續作《Royal Stone》卻只留在日本，也從未單獨再推出。編號 G-3425，四個來源的定價都是4,800日圓，完整品少不了那張紙地圖。兩家店最乾淨的搜尋都是完整日文標題。
  • 2026-10-10

    《Sylvan Tale》：SEGA 只在日本發售的 Game Gear 動作 RPG

    SEGA 從未在日本以外發售《Sylvan Tale》，而它的卡帶帶著兩組商品編號——SEGA 自家紀錄上的那一組，在商店裡什麼都搜不到。它也是本系列最便宜的完整品，配樂出自《飛龍騎士 RPG》的作曲者之手。
  • 2026-10-09

    《Defenders of Oasis》：SEGA 1992年的一千零一夜 RPG，以及為什麼只有日文名找得到它

    Sega CS2 在1992年為 Game Gear 打造的少數原創 RPG，還給了它自動存檔。評價好、排行榜待了四個月，卻從沒有續作。日版編號是 G-3404——而英文標題在那兩家日本商店都搜不到任何東西。

    惡魔城開發史 第4回：掌機世代——目錄裡的商品編號多了一截

    在Game Boy Advance與Nintendo DS上，Kataban目錄存的商品編號是AGB-A2CJ-JPN-1與NTR-ACVJ-JPN-2這樣的形式。五個裡有四個照原樣搜會回來HTTP 404與零筆；把-JPN那一段切掉就變成有效的搜尋語，而Buyee對這兩個編號完全不回應。系列開發史五部曲第4回。
