Kataban 部落格

《Baku Baku Animal》登上 Game Gear：SEGA 的街機益智遊戲放進口袋，以及把名字少登錄一個詞的那家店

2026-10-12

  • Game Gear
  • 益智
  • 1990年代
  • 世嘉

《Baku Baku Animal》——全名ばくばくアニマル 世界飼育係選手権，大意是「Baku Baku Animal：世界飼育員錦標賽」——於1996年1月26日在日本以 Game Gear 卡帶發售，未稅 3,800円。它起初是1995年4月推出的街機益智遊戲，由 Sega AM3 製作，也就是後來成為 Hitmaker 的團隊；之後又移植到 Saturn、Windows，以及巴西的 Master System。

這是「始終沒有續作」這個系列的最後一篇 Game Gear 作品，也是走得最遠的一款：Game Gear 版也在北美與歐洲發售，名稱就是單純的《Baku Baku》，而遊戲本身登上了四種家用主機。它仍然從未有過續作。

這也是最容易買錯東西的一篇。五個版本共用一個標題，其中最便宜的是 Saturn 光碟，而駿河屋登錄這捲 Game Gear 卡帶時用的名字，比官方名稱少了一個詞。

  • 日文標題：ばくばくアニマル 世界飼育係選手権。由 SEGA 發行；街機原版由 Sega AM3 開發
  • Game Gear 卡帶：1996年1月26日 · 未稅 3,800円 · 4 Mbit
  • 商品編號：G-3378，出自 SEGA 自家的軟體清單、Sega Retro 與駿河屋的收購頁。海外的 Game Gear 卡帶是 2451（北美）與 2451-50（歐洲）
  • 同名的其他版本：街機（1995年4月）、Saturn（1995年11月，1997年另有廉價再版）、Windows（1996年），以及只在巴西發售的 Master System 移植版（1998年）
  • 再發售：2020年藍色 Game Gear Micro 的四款內建遊戲之一，與《Sylvan Tale》同在一台
  • 續作：沒有。有兩個手機版（2002年與2013年）和一款衍生作品《Baku Baku Camera》（2015年）——是移植與外傳，不是第二部
  • 要買的話：兩家店都搜ばくばくアニマル ゲームギア。2026年9月21日，駿河屋有一捲完整品 ￥6,000，以及市集四捲，從 ￥2,880 起

《Baku Baku Animal》是什麼？Game Gear 版怎麼玩？

這是一款有動物園的落下型益智遊戲。英文維基百科說明了規則：動物方塊與食物方塊一起落下，動物落在牠喜歡的食物旁邊時——例如猴子挨著香蕉——就會把它吃掉。一隻動物一口吃掉的相連食物方塊越多，得分越高，而每吃一口都會讓額外的方塊掉進對手的場地。對手再也放不下方塊時，你就贏了。

故事只有一行長，但夠用了。一位國王要為女兒的眾多寵物招聘一名皇家飼育員，而你是應徵者之一的 Polly，一路擊敗其他候選人。

Hardcore Gaming 101 稱 Game Gear 移植版是「a strong adaptation of the arcade game」，並列出為了塞進掌機而改動的地方：

  • 畫面：沒有空間讓兩個場地並排，所以對手的場地縮成右邊的一個小框
  • 場地：整體更小，頂端有一個兩格寬的瓶頸
  • 密碼系統：可以從任何一關接著玩，很適合掌機
  • 路線：Normal 模式只能玩九關中的七關，有些對手也換了位置——Master Piggy 改為在 Hard 登場
  • 節奏：比街機版稍慢、稍簡單，電腦對手也沒那麼難纏

它的結論是，除了少了 Saturn 版的額外內容之外，Game Gear 移植版「easily one of the best versions of the game」。它也指出，這是唯一一個在北美發售時完整保留故事的版本。《Electronic Gaming Monthly》也評過 Game Gear 版，評論者 Andrew Baran 的總結是「non-threatening fun anyone can enjoy」。

有一件事我們無法確定：Game Gear 上的雙人對戰。Sega Retro 把本作歸在 Gear-to-Gear Cable 對應作品底下，而這條連線線只有 Game Gear 用，這指向兩台掌機之間的對戰模式。但 Hardcore Gaming 101 與兩個維基百科條目都沒有描述它，所以請把連線對戰當成「很可能有」，而不是已經確認。

日版卡帶是哪一版？編號是多少？

日版 Game Gear 卡帶是 G-3378，而且這一次難得有三個來源。

SEGA 自家的 Game Gear 軟體清單給出的那一行是 1月26日 | ばくばくアニマル 世界飼育係選手権 | パズル | 3,800円 | G-3378 | 4M。Sega Retro 的發售表在日本 Game Gear 版的欄位給的是 G-3378，日期與價格相同。而駿河屋這捲卡帶的收購頁（管理編號 166000189）寫著型番 G-3378，條碼為 4974365133788。

我們也在駿河屋查了它前後的編號。G3376 回傳忍空2 天空龍への道，G3377 回傳忍空外伝 ヒロユキ大活劇，G3380 回傳バーチャファイターミニ，全都與 SEGA 的清單一致。G3379 與 G3381 不在 SEGA 的清單上，兩者也都沒有回傳任何 Game Gear 遊戲。這一段是一致的。

文化廳媒體藝術資料庫把這捲卡帶記為 M753725，有日期、發行商與 3800円 (税抜)，但沒有 schema:productID，也沒有條碼。我們在2026年9月21日根據上面三個來源，把 G-3378 補進了 Kataban 目錄。

接著是同名的其他卡帶與光碟。Sega Retro 列出的海外 Game Gear 版，北美是 2451（1996年5月）、歐洲是 2451-50（1996年6月–7月），標題都是《Baku Baku》。日版 Saturn 光碟是 GS-9040（1995年11月10日），廉價的サタコレ再版是 GS-9144（1997年4月25日）。另有1996年的日版 Windows 版，以及 SEGA 在巴西的經銷商 Tec Toy 於1998年在當地推出的 Master System 移植版，Sega Retro 形容它與 Game Gear 版幾乎完全相同。我們查的那天，兩家日本商店都沒有出現海外卡帶，Saturn 光碟卻到處都是。

當年定價多少？現在要多少？

四個來源說法一致：媒體藝術資料庫記的是 3800円 (税抜)，SEGA 的軟體清單印的是 3,800円，Sega Retro 給的是 ¥3,800，駿河屋的定価欄寫的是 4,180円——也就是 3,800円 加上今天10%的消費稅。所以定價是未稅 3,800円。

2026年9月21日，駿河屋有：

  • 完整品，現貨：￥6,000（標示為新到貨）
  • 另有市集一行，￥2,880，共四捲二手

當天其他 Game Gear 條目全部缺貨。2026年9月21日，這家店的收購頁對一捲開價 3,000円——是它賣價的一半。2026年9月21日，Buyee 上這款遊戲的 Game Gear 商品總共正好2筆：一捲卡帶和一本說明書。

再對照 Saturn 光碟。2026年9月21日同樣的駿河屋搜尋裡，1995年的 Saturn 版有一行市集，從 ￥520 起、共32片，廉價再版則有現貨 ￥1,400。Game Gear 卡帶的價格是光碟的好幾倍。這正是只打標題在這裡會踩雷的原因：頁面上最便宜的價格，很可能屬於錯的機種。

為什麼沒有續作？

Hardcore Gaming 101 說得很直白。SEGA 幾度想在《魔法氣泡》與《Columns》旁邊再添新的益智系列，《Baku Baku Animal》就是其中一次嘗試——「much like ChuChu Rocket!, it never got the chance to become a franchise」。同一篇文章說，這是 AM3 的「one and only shot at the puzzle genre」。

實際存在的東西，老實列出來，是移植與一款外傳：

  • 2002年：一個手機版——據 Hardcore Gaming 101，這是街機版為 Java 手機精簡過的移植，只在日本配信
  • 2013年：第二個手機版，Sega Retro 列為 Android 版，Hardcore Gaming 101 則形容它是重新設計、動物更可愛的版本，同樣只在日本
  • 2015年：《Baku Baku Camera》，Sega Retro 將它列為衍生作品

這些都不是第二部。手機版是同一款遊戲換到新的硬體上，衍生作品則是借用名字的另一類遊戲。按本系列的標準——有編號的續作，或換了名字、但明確可認定的後繼作——《Baku Baku Animal》從未有過續作。

我們也查了 SEGA 悄悄讓舊作續命的那兩個下載服務。Sonic Cafe（2001年起的 i-mode 服務）的完整標題清單裡沒有《Baku Baku》；唯一的 Baku 是《Taisen! Bakudan Daifuugou》，那是另一款遊戲。ゲーム図書館（1990年11月起透過 Mega Modem 提供的服務）也沒有，這並不意外——這個服務比本作早了五年開始。

唯一一次現代再發售，和《Sylvan Tale》得到的是同一次。2020年10月6日，SEGA 推出了 Game Gear Micro，一台鑰匙圈大小的主機，共四種顏色、每色內建四款遊戲，而《Baku Baku Animal》就在藍色款裡。Hardcore Gaming 101 指出，Game Gear 版是唯一一個有過任何形式現代再發售的版本。

今天買得到嗎？該買哪一捲？

買得到，但數量不多。只要把缺貨商品也顯示出來，駿河屋一共有5個 Game Gear 條目。2026年9月21日的情況如下：

  • ばくばくアニマル世界選手権——完整品，現貨 ￥6,000，市集四捲從 ￥2,880 起（價格為2026年9月21日）
  • …(箱説なし)——只有卡帶。缺貨
  • ランクB)…——店家的B級。缺貨
  • [説明書のみ]…——只有說明書。缺貨
  • [外箱のみ]…——只有外盒。缺貨

最後兩個不是遊戲。請讀標題最前面的中括號：説明書のみ是說明書，外箱のみ是外盒。

在 Buyee，2026年9月21日的2筆 Game Gear 商品，一筆是標題為【GG】ばくばくアニマル世界飼育係選手権的卡帶，另一筆是單獨的說明書。下標前請先讀商品標題：商品編號找到的唯一一件 Game Gear 商品，就是那本說明書。

海外卡帶是存在的，所以值得知道你眼前的是哪一捲。北美與歐洲的卡帶叫《Baku Baku》，帶著 2451 或 2451-50；日版寫的是ばくばくアニマル，帶著 G-3378。如果你要的是英文文字，該找的是海外卡帶。本指南講的是怎麼找到日版。

兩家店各要怎麼搜？

兩家店要的是同一組詞：短標題加機種名，ばくばくアニマル ゲームギア。

駿河屋：加上機種名，而且不要打完整標題。ばくばくアニマル ゲームギア顯示缺貨後回傳5筆，2026年9月21日時全部是這捲卡帶。陷阱在完整的官方標題：ばくばくアニマル 世界飼育係選手権回傳0筆，因為這家店把卡帶登錄為ばくばくアニマル世界選手権——少了飼育係，也就是「飼育員」這個詞。用店家自己的寫法，回傳的是同樣的5筆。短標題ばくばくアニマル也找得到它們，但被埋住了：顯示缺貨後18筆，其中5筆是 Game Gear、5筆是 Saturn、8筆是街機相關物品——一片基板、操作說明卡與說明書。片假名寫法バクバクアニマル回傳同樣的18筆。

在駿河屋，商品編號幫不上什麼忙。G3378 顯示缺貨後回傳13筆，只有2筆是本作（完整品與B級品）；其餘包括 junk（現況出售）的 PlayStation 2 主機與液晶掌上遊戲機。帶連字號的 G-3378 現貨104筆、含缺貨254筆，第一頁沒有一筆是本作，因為駿河屋會從連字號把編號切開。英文標題回傳0筆。

Buyee：同樣的詞，其他寫法都沒這麼好用。ばくばくアニマル ゲームギア回傳2筆，兩筆都是本作。短標題ばくばくアニマル回傳19筆，其中只有2筆是 Game Gear，其餘大多是 Saturn 相關商品。完整官方標題回傳12筆，其中只有那捲卡帶是 Game Gear——其餘是 Saturn 與 Windows 版。和駿河屋不同，Buyee 不在乎少掉的那個詞：ばくばくアニマル世界選手権回傳同樣的12筆。

在 Buyee，編號與英文標題都不管用。G-3378 回傳5筆，唯一相關的是那本說明書。G3378 回傳302筆，前99筆中唯一相關的也是那本說明書。Baku Baku Animal 回傳118筆，前一百筆裡有那本說明書和一套 Saturn 版。西方名稱 Baku Baku 回傳12,018筆音響器材、BAKUNE 睡衣與《爆漫王。》漫畫，前99筆沒有一筆是本作。

這一款為什麼要用 Kataban 搜？

因為 Kataban 把每個版本都列成獨立的一筆，並標上機種，而這正是這款遊戲在商店裡的問題所在。

2026年9月21日在桌機瀏覽器上確認：ばくばくアニマル、完整官方標題與 Baku Baku Animal 各回傳3筆——2筆 Saturn 與這捲 Game Gear 卡帶，每一筆都標著機種。Baku Baku 則回傳4筆：同樣這3筆，加上一款無關的2012年 Nintendo 3DS 遊戲ゴン バクバクバクバクアドベンチャー。G-3378 與 G3378 各只回傳這捲 Game Gear 卡帶，因為我們在2026年9月21日把 SEGA 清單上的編號補了進去；在那之前兩者都回傳0筆，因為媒體藝術資料庫這一筆沒有商品編號。

商店用的詞在這裡也管用。ばくばくアニマル ゲームギア，這個在兩家店都最好用的詞，回傳1筆，就是這捲卡帶；片假名寫法バクバクアニマル回傳3筆，與平假名標題是同樣的3筆：自2026年10月13日起，搜尋查不到東西時，目錄會去掉機種名、並把平假名與片假名視為相同再查一次（2026年10月13日再確認）。有一件事不管用，值得說清楚。店家的寫法ばくばくアニマル世界選手権回傳0筆，因為目錄用的是官方標題。在日本店裡，要翻的假名是ハ。

那 Saturn 版呢？

它是大多數人記得的那個版本，也落在這份購買指南之外，但不提它反而奇怪。

評論者喜愛的是 Saturn 版。英文維基百科整理了那些讚譽：《Maximum》稱它是「the best ‘next generation’ puzzle game we’ve seen to date」，《Sega Saturn Magazine》則說它有「some of the most addictive puzzle play since Tetris」。它也是今天在日本玩到這款遊戲最便宜的方式，而且便宜得多。如果你只是想玩《Baku Baku Animal》，Saturn 光碟是簡單的答案。如果你要的是口袋版——Hardcore Gaming 101 評為最佳版本之一的那個——那就是 Game Gear 卡帶，而你得刻意去搜它。

一款街機益智遊戲，移植到四種家用主機，從日本一路賣到巴西，登上了藍色 Game Gear Micro，卻依然沒有第二部。本系列的 Game Gear 篇到此結束，而貫穿六捲卡帶的是同一條線：本系列的六組購買連結，沒有一組用的是商品編號。《Ax Battler》的編號在 SEGA 自家的清單上印錯了；《Sylvan Tale》的店家乾脆把它歸在另一組號碼底下；《Royal Stone》的編號只管用一半；而這一款的編號，13筆裡只找到兩捲。找到每一款遊戲的都是標題——但從來不是同一種形式的標題，而這一次，甚至不是盒子上的那個形式。
