Kataban 部落格

《拉格朗日點》登上紅白機：Konami 1991年的 FM 音源 RPG，與它的編號 RC851，以及如何分辨英文的 NES 仿製卡帶

2026-10-18

  • 紅白機
  • RPG
  • 1990年代
  • 科樂美
  • 日本限定

《拉格朗日點》於1991年4月26日在日本以 Konami 的紅白機卡帶發售，未稅 8,500円。標籤上的標題是用拉丁字母拼的 LAGRANGE POINT™，下方印著ラグランジュポイント。這是一款以22世紀的太空殖民地為舞台的科幻角色扮演遊戲，也是已發售的遊戲中，唯一用上 Konami VRC7 晶片內建 FM 音源的一款。

這是「始終沒有續作」這個系列的一篇。我們找不到 Konami 推出的任何續作、外傳、重製版或移植版，也找不到任何參與製作的人解釋原因的說法。它留下來的，是曾以 CD 與黑膠唱片再版的音樂，以及一個英文的粉絲翻譯。

  • 日文標題：ラグランジュポイント，由 Konami 發行。標籤、外盒與說明書上都以拉丁字母印著 LAGRANGE POINT™ 的標誌，但這款遊戲沒有英文版
  • 紅白機卡帶：1991年4月26日 · 未稅 8,500円
  • 商品編號：RC851，不帶連字號，印在正面標籤的「© KONAMI 1991」下方
  • 音效：已發售的遊戲中，唯一使用 Konami VRC7 晶片 FM 合成的一款
  • 僅限日本：外盒與說明書上都印著「FOR SALE and USE IN JAPAN ONLY」
  • 沒有第二部：沒有續作、外傳、重製版或移植版。原因沒有留下紀錄
  • 要買的話：在駿河屋搜 RC851。做成 NES 形狀的卡帶，或帶有英文文字的卡帶，都是仿製卡帶

《拉格朗日點》是什麼？怎麼玩？

外盒背面交代了故事的開場。22世紀，太空殖民地イシス（Isis）爆發了生物災害，突變體幾乎在一瞬間就占領了整個殖民地，人類展開漫長的抵抗；故事跟隨少年 Jin 和他的夥伴，對抗如今統治殖民地的 Bio 軍。外盒上的標語是感動は宇宙を貫く！コナミの放つSF-RPG超大作——大意是「貫穿宇宙的感動：Konami 的科幻 RPG 巨作」——並預告了合成武器的系統與動畫風格的過場畫面。外盒用來稱呼這場災害的詞是バイオハザード，比 Capcom 把它定為《惡靈古堡》的日文標題早了五年。

外盒上也印著製作人員。角色插畫出自漫畫家細野不二彥（Fujihiko Hosono），音樂則由署名「EX. REBECCA」的高橋教之（Noriyuki Takahashi）與土橋安騎夫（Akio Dobashi），以及 Konami 的社內音效團隊 Konami Kukeiha Club（科樂美矩形波俱樂部）負責。製作協力的署名是《Family Computer Magazine》的芸夢工房。外盒上還有一行值得知道：シャープのC1ではご使用になれません——它無法在夏普的 C1 上執行，那是一台內建紅白機的電視。

《拉格朗日點》的聲音有什麼不同？

卡帶裡裝著 Konami 的晶片 VRC7，它在紅白機本身的音效之外，再加上 FM 合成。外盒自己就這麼說：新LSI「VRC7」がファミコン初のFM音源を実現——「新 LSI『VRC7』讓紅白機首度實現 FM 音源」。Konami 在2017年這款遊戲發售週年那天，也在官方 X 帳號上說了同樣的話：ファミコン初のFM音源を実現させています。請注意 Konami 宣稱的是什麼：是第一款。它沒有說是唯一一款。

它後來也一直是唯一的一款，這一點來自其他來源，而它們的說法一致。由紅白機與 NES 程式設計者經營的技術維基 NESdev Wiki 說，VRC7 的音效「只用在一款遊戲上，也就是《拉格朗日點》」。Hardcore Gaming 101 稱它是「唯一一款善用」這枚晶片的作品。日文維基百科說它是唯一實裝 FM 音源的紅白機遊戲。VRC7 晶片本身也出現在《Tiny Toon Adventures 2》裡，但 NESdev 指出那捲卡帶並沒有使用它的音效。NESdev 也把這個 FM 部分描述為 Yamaha YM2413（OPLL）的精簡衍生版，有六個 FM 聲道，而 YM2413 有九個；這個細節的依據是 NESdev。

《拉格朗日點》曾經在日本以外發售嗎？

沒有。外盒背面與說明書封底都印著 「FOR SALE and USE IN JAPAN ONLY」，外盒還附有本品の輸出、使用営業及び賃貸を禁じます（「禁止出口、營業使用及出租本產品」）。英文維基百科說這款遊戲只在日本發售，從未在地化。我們沒有找到任何西方版本曾經發表過的紀錄。

不要被拉丁字母誤導。標籤、外盒與說明書上寫著 LAGRANGE POINT™，但那是標誌，不是英文版。除此之外，外盒上的英文只有那行出口警語、「MADE IN JAPAN」，以及製作人員署名「EX. REBECCA」。沒有英文的標題行，也沒有英文標語。

它為什麼留在日本，同樣沒有留下紀錄。有一個來源提出了理由：復古遊戲新聞網站 RetroCollect 在2014年寫道，VRC7「大幅增加了生產成本，這可能就是」這款遊戲從未在地化的原因。這是我們找到的唯一來源，而它說的是「可能」。日文維基百科引用 RetroCollect，重述了這一點。

日版卡帶是哪一版？編號是多少？

媒體藝術資料庫把這捲卡帶記為 M727043：標題 LAGRANGE POINT，取自卡帶標籤，另一個名稱是ラグランジュポイント；紅白機；1991-04-26 由コナミ株式会社發行；商品 ID RC851；8,500円 (税抜)。

另外兩個地方的編號也一致。NES Cart Database 把 RC851 列為正面標籤的 ID，而在駿河屋搜 RC851，回傳的只有這款遊戲。日版卡帶的編號是 RC851，不帶連字號。在卡帶上，它印在正面標籤的右上角，就在「© KONAMI 1991」的正下方。說明書封面的右上角與外盒兩端的封口蓋上也有，但外盒的側標上沒有。我們是在 NES Cart Database 的掃描圖，以及一位日本賣家拍的照片上確認標籤的。

定價是未稅 8,500円。這是媒體藝術資料庫的數字；駿河屋顯示 定価：￥9,350，那是同一個價格加上今天10%的消費稅：8,500 × 1.1 = 9,350。

為什麼從來沒有《拉格朗日點2》？

我們不知道，而且我們找過。我們找不到 Konami 以這款遊戲為基礎做出的任何續作、外傳、重製版或其他遊戲，也找不到任何參與製作的人解釋為什麼沒有第二款的訪談或貼文。

你會讀到的其他說法，來自維基和粉絲。日文維基ゲームカタログ@Wiki列出了幾個可能的理由——製作人員已經離開 Konami、開發資料下落不明、銷量不佳之後在公司內部評價不好，以及包括標題在內的許多元素來自讀者投稿，權利可能很難處理。它說這些是「從相關人士的發言等可以推想的」理由，但沒有說是誰說了什麼，而且在沒有出處的情況下，斷言 Konami 把這款遊戲評為失敗作。其他粉絲頁面則猜測它只是賣得不好。請把這一切都當成猜測。

這款遊戲也從未回來過。我們找不到任何移植、合輯或下載版：它不在維基百科的 Virtual Console、Nintendo Switch Online、Console Archives、Classic Mini 或 Project EGG 作品列表裡。請把這當成「沒有找到」，而不是證明。音樂則是另一回事。EGG MUSIC 在2015年以《LAGRANGE POINT SOUNDTRACKS RETURNS》之名把原聲帶再版成 CD，環球音樂則在2024年於ミュージック フロム コナミアンティークス系列中，把它和《Falsion》配成一組，推出了黑膠唱片。

有哪些英文版本？

英文的粉絲翻譯是存在的。粉絲經營的資料庫 Romhacking.net 列出它由粉絲團體 Aeon Genesis 推出：完全可玩，1.01版，日期為2014年11月5日。根據同一個頁面，這個計畫最初屬於另一個團體 J2E Translations，大約在2007年轉交給 Aeon Genesis。RetroCollect 在2014年10月23日報導了這個翻譯。

仿製卡帶也有在賣，而且是做成 NES 的形狀。2026年9月25日，在 eBay 搜 Lagrange Point 的第一筆結果，是一捲全新、NES 形狀的卡帶，商品標題為「Lagrange Point - Nintendo NES - GAME ONLY」，庫存超過十件；網路商店 n-bro8 則以17.99美元販售「Lagrange Point For Nintendo NES」，標明是72針的卡帶。兩個頁面都沒有說裡面是哪個版本的遊戲。其他店家以名稱列出英文版——搜尋結果裡可以看到「Lagrange Point (English Version)」之類的標題——但我們打不開那些頁面。這些是店家的商品頁。Konami 從未為這款遊戲製作過 NES 卡帶。

要怎麼分辨原版卡帶和仿製卡帶？

就我們找到的所有來源的紀錄而言，Konami 只以日本紅白機卡帶的形式推出過《拉格朗日點》。任何做成 NES 形狀、或遊戲文字是英文的《拉格朗日點》卡帶，都是仿製卡帶。

  • 編號：原版在正面標籤的右上角、「© KONAMI 1991」下方印有 RC851。eBay 搜尋結果最上面的那捲仿製卡帶有「© KONAMI 1991」，卻沒有 RC851
  • 封印：那捲仿製卡帶的標籤上，還有一條寫著「Nintendo Entertainment System」的黑色帶子，以及「Official Nintendo Seal」。任天堂從未核准這款遊戲在 NES 上推出，所以這個封印不是真的
  • 外形：紅白機卡帶有60針，不加轉接器插不進北美或歐洲的 NES。能直接插進 NES 的卡帶，就不是1991年推出的那一捲
  • 遊戲文字：原版的訊息與對話是日文。對話是英文，就代表是粉絲翻譯
  • 商品頁的用字：不要指望賣家會寫出「repro」。上面那筆 eBay 商品就沒有寫

還有聲音的問題。NESdev 與 ConsoleMods 這兩個由社群經營的技術維基指出，NES 的72針卡帶接頭少了紅白機的音效針腳，所以紅白機遊戲的額外音效晶片，在未改裝的 NES 上是聽不到的。這是關於硬體的一般性說明，不是對任何一捲仿製卡帶的測試；我們沒有玩過仿製卡帶。如果你想聽 VRC7 的 FM 音源，穩妥的選擇是把原版卡帶插在紅白機上。

如果你在日本當面購買，可以把這句話給店員看：これは1991年のオリジナル版ですか？——「這是1991年的原版嗎？」

每家店各要怎麼搜？

駿河屋：用編號，在遊戲分類裡搜。RC851 在預設畫面回傳1筆、顯示缺貨後5筆，全都是這捲卡帶。帶連字號的 RC-851 回傳同樣那幾筆，外加一台 AV 切換器。日文標題在預設畫面回傳2筆、顯示缺貨後14筆，也全是這款遊戲，包括單獨販售的外盒與說明書。若在全站搜尋，標題還會帶出攻略本，以及樂團無限開關（Sukima Switch）2010年巡迴演唱會的周邊商品，所以請保持在遊戲分類。用拉丁字母搜 Lagrange Point，回傳的只有《MARGINAL#4》的商品，那是一個媒體企劃，裡面有一個名叫 LAGRANGE POINT 的團體。

Buyee：標題加上紅白機的日文名稱。ラグランジュポイント ファミコン回傳42筆，其中28筆是這款遊戲——26捲卡帶和2本單獨的說明書。其餘是原聲帶 CD、攻略本、1991年的宣傳單和整批合售。只打標題回傳74筆，其中屬於這款遊戲的同樣是那28筆；多出來的是無限開關的巡迴演唱會、「LAGRANGIAN POINT」、《MARGINAL#4》的周邊，以及更多原聲帶。RC-851 回傳2筆，都是這款遊戲，但2筆太少，不能依靠；不帶連字號的 RC851 則回傳412筆，幾乎全是汽車與遙控模型的零件。

eBay：英文標題加上「famicom」。Lagrange Point famicom 回傳19筆完全符合的結果：16筆是這捲卡帶，1筆整批合售，1本攻略本，還有1筆標題只寫著「Lagrange Point」。它也把 NES 仿製卡帶排除在外。單獨的 Lagrange Point 回傳205筆，排在最前面的是那捲仿製卡帶，其間擠滿了一位名叫 Carlos Lagrange 的球員的棒球卡、一張《MARGINAL#4》的 CD，以及一張黑膠原聲帶。Lagrange Point NES 回傳12筆，那捲仿製卡帶也在其中。編號在 eBay 上不管用，而日文標題回傳的是叫做 La Grange 的地方的東西。

會混進來的東西，以及怎麼認出它們：原聲帶會寫 CD、LP 或サウンドトラック，也包括《SOUNDTRACKS RETURNS》和 Konami Antiques 系列；無限開關的商品會寫「LAGRANGIAN POINT」與「TOUR 2010」；攻略本是完全攻略本；宣傳單是チラシ；《MARGINAL#4》的商品會寫出這個企劃或它的角色名。遊戲的商品頁會寫ファミコン、FC 或 Famicom，而且常常寫著 RC851。

這一款為什麼要用 Kataban 搜？

因為在大多數店家，拉丁字母的標題找到的都是錯的東西，而編號只在部分店家管用。Kataban 把編號和日文標題並排列出。搜 RC851、Lagrange Point 或ラグランジュポイント，就會找到這捲卡帶。在日本的二手遊戲店，例如 Book-Off，紅白機遊戲常常依五十音順序上架，所以要翻的假名是ラ。

一款做到了其他紅白機遊戲都沒做到的事，之後卻什麼也沒有接續的遊戲。《拉格朗日點》留在日本，從未有第二部，除了音樂和粉絲翻譯之外，也從未回來過。如果你要的是1991年那一捲，請在標籤上的「© KONAMI 1991」下方找 RC851，並把它插在紅白機上，聽聽那 FM 音源。
