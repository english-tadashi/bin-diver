《Viewpoint》：Neo Geo AES 上手繪的等角射擊遊戲，與晚了26年才到的續作

2026-11-04

  • Neo Geo
  • 射擊
  • 1990年代
  • Sammy
  • Aicom

《Viewpoint》是 Aicom 為 Sammy 開發的捲軸射擊遊戲，也是 Sammy 唯一掛上自己名字的 Neo Geo 遊戲。它1992年10月進入大型電玩，1992年12月11日同一款遊戲以 Neo Geo AES 卡帶發售，商品編號 NGH-051，72 Mbit，未稅 25,000円，卡帶側標印的日文標題是ビューポイント。

這是「有資格再出一代、卻始終沒有續作」這個系列的第七篇。而《Viewpoint》正是這句話不再成立的那一篇——不是因為續作推出了，而是因為它被公布、被取消，然後在原定發售日的26年後被保存人士傾印出來、放上網路。這也是本系列第三次碰到同一家工作室：Aicom 在1992年做了這款，1995年做了《Pulstar》，之後改名為 Yumekobo，在1998年做了《Blazing Star》。本文整理這款遊戲的畫面從何而來、標籤上的編號代表什麼、現在值多少、該去哪裡買——以及2025年11月發生了什麼事。

  • 日文標題：ビューポイント，由 Aicom 開發，Sammy 與 SNK 發行
  • Neo Geo AES（家用卡帶）：1992年12月11日 · 商品編號 NGH-051 · 72 Mbit · 未稅 25,000円
  • 大型電玩（Neo Geo MVS）：1992年10月 · Sammy 唯一的 Neo Geo 作品
  • Neo Geo CD：1995年2月25日 · 商品編號 AICD-051 · 由 Aicom 重新編寫
  • 手繪的 3D：等角視角的畫面是一筆一筆手繪的——沒有預渲染軟體，也沒有 3D 硬體
  • 三種炸彈，六個關卡：從你身後往畫面上方捲去的火焰波、圓形的新星爆發，以及追蹤型的小飛彈
  • 續作被取消了：《Viewpoint 2064》以 Nintendo 64 公布，預定1999年11月11日推出，整個2000年一延再延，2001年放棄
  • 然後又沒有：2025年11月24日，《Viewpoint 2064》的最終版本被傾印出來，上傳到 Internet Archive
  • 它值多少：2026年9月20日，駿河屋沒有任何一捲卡帶，並開出 ￥180,000 向你收購——但 Neo Geo CD 版就擺在架上，￥6,370

《Viewpoint》是什麼？為什麼它長這個樣子？

它是一款從斜角看過去的射擊遊戲。維基百科直接寫出它的血統：「isometric-scrolling gameplay was largely inspired by Sega’s Zaxxon」，美術上則受到《鐵板陣》與《R-Type》的影響。你是斜著飛過一片網格，而不是筆直往下飛，所以每一種敵人的出現模式都得同時從兩個軸向去讀，機體底下的影子和機體本身一樣重要。

除了一般射擊，還有三種炸彈，各自用不同方式利用這種幾何：一種讓一道火焰波從你身後往畫面上方捲去，一種以圓形的新星爆發引爆，一種發射追蹤型的小飛彈。關卡共有六個。兩名玩家平常是輪流玩，不過在 Service Mode（服務模式）裡可以打開同時遊玩——如果你買的是大型電玩基板而不是卡帶，這一點值得知道。

值得停下來看的是畫面怎麼做出來的。那是1992年，大家正開始談論預渲染 CG 的一年，而維基百科寫得很明確：「The game’s 3D graphics were drawn entirely by hand, as opposed to using pre-rendering software or 3D hardware.」那些金屬球體和分節的昆蟲，每一個都是由人一格一格畫出來的。配樂由 Sizlla Okamura 負責。

當年的評價非常驚人。《GameFan》給了99.5%與99%，並稱它是「the best game on the system so far」。《GamePro》每一項都給滿分5分。《Computer and Video Games》給95%，《Sinclair User》96%，《Fami通》30/40。後來的家用移植就沒那麼順利——Genesis 版與 PlayStation 版因技術上的妥協和操作而評價兩極，IGN 給 PlayStation 移植版2/10，評論者稱它「unbelievably hard」。如果你只在 PlayStation 光碟上玩過《Viewpoint》，那你其實還沒真正玩過它。

是誰做的？為什麼 Sammy 的名字只出現在一款 Neo Geo 遊戲上？

做它的是 Aicom。這家工作室1988年成立，維基百科的開發一節提到它以《The Legendary Axe》與《The Astyanax》聞名。本站的老讀者應該見過它：Aicom 在1990年為 Jaleco 開發了紅白機上的《Magic John》，也就是在北美成為《Totally Rad》的那款遊戲。之後它在1995年為 Neo Geo 做了《Pulstar》，1996年脫離 Sammy、拿了 SNK 的資金並改名為 Yumekobo，以這個名字在1998年做了《Blazing Star》。本系列有三款遊戲出自同一棟樓。

掛名的另一半是 Sammy，而這是它唯一一次出現在 Neo Geo 遊戲上。這件事我們查過，而不是照抄：在 MAME 的 Neo Geo 驅動程式原始碼裡，廠商欄位含有 Sammy 的只有 viewpoin 與它的原型 set viewpoinp——同一款遊戲出現兩次——而 MAME 的 Neo Geo CD software list 裡完全沒有 Sammy 的作品。MAME 記錄的掛名是「Sammy / Aicom」。維基百科用自己的話說了同一件事：《Viewpoint》是 Sammy 唯一的 Neo Geo MVS 作品。

對一家規模龐大的公司來說，這是個奇怪的事實。Sammy 是大型電玩與娛樂機台的巨頭，後來還與 Sega 合併；在 SNK 的硬體上，它只發行過一款遊戲，就是這一款。日版卡帶印著版權標示 ©SNK/サミー工業——SNK 與 Sammy Industries 並列——這已經是這件實物本身對這層合作關係最接近說明的地方了。

哪一版才是日版卡帶？編號是什麼？

NGH-051，而且和本系列上一篇不同，這裡沒有位數的陷阱。Neo Geo 家用卡帶的編號在1990年代後期之前都是三位數，之後 SNK 才改成四位數；1992年穩穩落在三位數的時代，我們也用最直接的方法確認過——在駿河屋搜尋四位數的 NGH0510，什麼都找不到。

這個編號來自三個互相吻合的獨立來源：駿河屋卡帶商品頁上的型番欄位寫 NGH-051，日本的遊戲目錄 Pico Pico Daihyakka 給 型番：NGH-051，satakore 的日版 AES 頁面也列出同一個編號。這次 MAME 幫不上忙——它的 viewpoin 記錄了廠商與年份，卻沒有商品編號——而曾為《Blazing Star》提供條碼的 VGCollect，這款遊戲的欄位寫的是「Item Number: NA」。

有意思的是光碟。1995年2月25日的 Neo Geo CD 版，商品編號是 AICD-051，而這個編號不需要任何人去拼湊：它就以 schema:productID 的形式登錄在文化廳媒體藝術資料庫裡，這在 Neo Geo 作品中很少見。MAME 的 Neo Geo CD software list 給的也是同一個 serial。AICD 是 Aicom 自家的前綴——和 ADK 的 ADCD 編號是同一種模式——而資料庫的版權欄位說明了原因：光碟上同時印著 ©SAMMY 1992 與 REPROGRAMMED ©AICOM 1995。開發商把自己三年前的遊戲為 CD 硬體重新做了一遍，並在成品上放上自己的型錄編號。

有兩個日期要小心。媒體藝術資料庫把大型電玩版記為1992年10月，維基百科則寫1992年11月20日，所以本文對基板只寫「1992年10月」，不寫日期。卡帶的日期沒有爭議：1992年12月11日，資料庫和駿河屋的商品頁都這樣寫。

當年賣多少？現在值多少？

未稅 25,000円，而這一次有三個來源一起這樣說：媒體藝術資料庫記錄為 25000円 (税抜)，Pico Pico Daihyakka 記錄為 25,000円，駿河屋的定価欄位寫 ￥27,500，也就是同一個數字加上現行的10%稅。數字對得上的時候，我們就寫出來。

如今，卡帶和光碟往相反的方向走。2026年9月20日，駿河屋沒有任何一捲卡帶可賣，並開出 ￥180,000 向你收購一捲。同一個網站上，Neo Geo CD 版有貨，品相美品（近全新），￥6,370——上市價格是 ￥6,380，所以一張近全新、31年前的光碟，賣得比當年新品還便宜10日圓。它的收購價是 ￥3,400。

卡帶與光碟之間超過25倍的差距，是這篇指南裡最有用的一件事。無論哪一種，都是同樣的六個關卡。

為什麼從來沒有續作——2025年又發生了什麼？

本來是會有的，而且這一次我們知道它的名字、平台，以及預定推出的日期。

《Viewpoint 2064》以 Nintendo 64 公布，由 Sammy 與 Racdym 開發。它在 Nintendo SpaceWorld 1999 展出，據 Time Extension 的說法也在東京電玩展上展出，預覽評價很好——IGN64 等媒體都給了熱烈的報導。設計上把初代的概念做成可以切換：經典的等角視角與機體後方視角，共15個區域、路線會分歧，正是《星際火狐64》帶起的那種形式。發售日定在1999年11月11日。

它沒趕上。整個2000年一再延期，然後在2001年悄悄取消。給出的理由很平淡：Sammy 在開發上遇到了問題。於是 Sammy 唯一的 Neo Geo 遊戲依然是獨一款，而續作則加入了那一長串只存在於預覽截圖裡的 N64 作品。

只不過它沒有一直待在那裡。2015年，一個可以玩的原型出現在 eBay 上，幾乎完成，可以玩到破關。接著在2025年11月24日，保存人士 Hard4Games 從一捲開發用卡帶中傾印出最終的「Master」版本，上傳到 Internet Archive——這個版本補上了先前原型缺少的東西，包括碰撞判定、宣傳時展示的介面，以及缺少的頭目戰。

本系列其他每一篇，都以一個缺席作結。這一篇以一個檔案作結。《Viewpoint》的續作預定在1999年11月的一個星期四推出，被取消了，然後在2025年11月變得可以玩——晚了26年，免費，來自那些不肯讓這些東西消失的人。

現在真的買得到 AES 卡帶嗎？

買得到，而且這是本系列到目前為止最容易的一款。

駿河屋，2026年9月20日：沒有卡帶，但其他東西很多。店家自家的這捲 AES 卡帶（商品 163000039）是品切れ。讓它連缺貨品一起顯示，這個標題會回傳43筆——各種品相等級的卡帶、光碟、大型電玩基板、操作說明卡，還有單獨一本說明書。這是一款經常經過這家店的遊戲，而不是從來不出現的那種。而且 Neo Geo CD 版真的有貨，￥6,370。

Buyee，同一天：ビューポイント ネオジオ 回傳11筆，而且每一筆都是這款遊戲——1捲 AES 卡帶、7張 Neo Geo CD，以及3件 MVS 的紙類附件。沒有任何一件無關的東西。這是本系列在任何一家店量到最乾淨的搜尋結果，和上一篇正好相反，那次同樣的搜尋找不到任何相關的東西。

eBay，同一天：Viewpoint Neo Geo 回傳103筆；第一頁的60筆中有47筆是這款遊戲，包括8捲 AES 卡帶，開價從約 ￥198,000 到約 ￥549,000，4套 MVS 套件，以及約30張 Neo Geo CD。沒中的大多是周邊商品——2張原聲帶 CD、3塊機台招牌、1張海報、1則雜誌廣告、1個複製外盒和1個馬克杯。

那到底能買到什麼？幾乎什麼都有，只是價格差得非常遠。光碟在日本是 ￥6,370，卡帶在海外是 ￥200,000 以上。老實的建議是先決定你想要的是玩《Viewpoint》，還是擁有那件1992年的實物，因為這兩個答案之間的差距大約是20萬日圓。

在每家店該怎麼搜尋？

駿河屋：用編號，但顯示的會是缺貨品。下面的連結會以連缺貨品一起顯示的方式打開 NGH051，回傳3筆，全都是這捲卡帶。自己輸入編號時，請打開缺貨品的顯示，因為卡帶缺貨，預設顯示會把它藏起來。加了連字號的 NGH-051 更差——7筆中只有3筆是本作，其餘是《Andro Dunos》與《NAM-1975》，因為駿河屋會在連字號處把編號切開，拿「051」去比對其他編號。光碟的話，AICD051 與 AICD-051 都回傳4筆，4筆全是本作。日文標題ビューポイント回傳今天值得買的兩樣東西：光碟，以及一捲 ￥26,100 的海外 Genesis 版。

Buyee：用標題加機種名。ビューポイント ネオジオ，11筆，筆筆都是本作。商品編號在這裡完全派不上用場——NGH-051 與 NGH051 都沒有任何結果——這是常見的模式：Buyee 搜尋的是賣家自由填寫的文字，而日本賣家寫的是標題，不是編號。

eBay：用英文標題加機種名。該用的搜尋是 Viewpoint Neo Geo。不要只搜 Viewpoint AES：它回傳15筆，其中只有9筆是本作，因為韓國網路小說《全知讀者視角》（Omniscient Reader’s Viewpoint）在英語圈市場很大，它的輕小說會和一台底片相機一起冒出來。商品編號在這裡同樣沒用——NGH-051 回傳0筆。

看標題，不要只看筆數。ROMカセット與 AES 是家用卡帶；CD、NCD、CD-ROM 與スピンカード是1995年的光碟和它的包裝；MVS、基板與インスト是大型電玩硬體和它的紙類附件；Genesis 或メガドライブ是1994年的海外移植版，是另一樣、也便宜得多的東西；OST、marquee（機台招牌）與 poster（海報）則根本不是遊戲。

為什麼要用 Kataban 找這一款？

因為兩個名字都有效，但少了兩個版本，而在開始讀商品之前，先知道哪個是哪個比較好。

2026年9月20日在桌機瀏覽器上確認：ビューポイント回傳2筆，Viewpoint 回傳同樣的2筆：1992年的 Neo Geo 卡帶與1995年的 Neo Geo CD 光碟。兩列資料都帶有英文標題，所以用哪一種語言都找得到。

2筆並不是全部，我們寧願直說。1994年12月推出過 Genesis 版，1996年1月推出過 PlayStation 版，而這兩者在媒體藝術資料庫裡都沒有資料列，所以都不會出現在這個目錄裡。這個資料庫記錄的是文化廳編目的日本發行作品，它對這款遊戲的收錄只到兩種 Neo Geo 形態為止。如果你要找的明確是 Genesis 卡帶，目錄幫不上你；駿河屋的日文標題搜尋可以。

商品編號從今天起也是入口。卡帶那一列本身沒有編號，這個欄位是依上面列出的三個來源在這裡補上的；而因為目錄在比對前會把符號去掉，NGH-051 與 NGH051 都會落在卡帶上。光碟不需要這種幫忙——它的 AICD-051 直接來自資料庫。在日本店裡的假名分類要找ヒ。
