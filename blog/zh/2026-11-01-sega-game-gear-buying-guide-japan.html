Sega Game Gear 購買指南：機型、區域鎖、常見故障與電源

2026-11-01

  • Game Gear
  • 1990年代
  • 世嘉

Sega Game Gear 沒有區域鎖，所以日版卡帶可以在日版、美版或歐版主機上執行，日版主機也能玩任何地區的卡帶。這讓日本成為買 Game Gear 的好地方。真正的風險是老化，不是地區：這些主機都已超過30年，電容失效正是許多機器螢幕變暗或沒有聲音的原因。以下說明如何分辨機型、要檢查什麼、哪種電源才安全，以及如何找遊戲。

  • 地區：沒有區域鎖。語言可能隨主機改變，另外有1款遊戲有已知的程式錯誤。
  • 付款之前：詢問喇叭、螢幕、電池接點的狀況，以及電容是否更換過。
  • 電源：6顆 AA 電池是安全的選擇。不要把日本的 100 V 電源轉接器直接插進 120 V 或 230 V 的插座。

Game Gear 有區域鎖嗎？

沒有。日文維基百科說，任何地區的軟體都能在同一台主機上玩；ConsoleMods 則說明得更詳細：主機只有一個地區設定，分為日本與出口兩種，而大多數遊戲都不理會它。

少數遊戲會讀取這個設定並隨之改變。在出口版主機上，Puyo Puyo 會切換成英文，並改名為 Puzlow Kids。在日版主機上，Streets of Rage 會變成 Bare Knuckle。所以日版卡帶能在你的主機上啟動，但大部分日文仍然是日文。

唯一的例外是 Pop Breaker，這款只在日本發售的遊戲在非日版主機上會停在標題畫面。ConsoleMods 認為這是程式錯誤，不是刻意鎖區。

要確認你看到的是主機本身，型號是最快的方法。SEGA 自家的硬體頁面列出了發售日與價格；各顏色的日期來自日文維基百科，Sega Retro 的日版機型中也列出相同的顏色。

Game Gear Micro 有什麼不同？

Micro 於2020年10月6日在日本發售，距離初代正好30年，未稅 4,980円。它是專用主機：每種顏色（黑、藍、黃、紅）內建4款遊戲，每種顏色的4款都不同。電源使用 USB 或2顆 AAA 電池。

如果你想玩日版卡帶，就買初代。如果你想玩某一種顏色內建的特定遊戲，又喜歡這種小巧的玩意，就買 Micro，並確認那款遊戲在哪個顏色裡。另外，Aleste Collection 的限定版也附了一台白色 Micro。

不要為了看電視而買 TV Tuner。日本已於2011年7月24日在47個都道府縣中的44個結束一般類比廣播，Sega Retro 也說，由於許多國家已改為數位訊號，這個調諧器現在幾乎不能用來看電視。它是收藏品。日文維基百科指出它還有影像輸入功能，可透過 A/V 線（HGG-3006）使用。

二手 Game Gear 通常哪裡會壞？

聲音和螢幕。Sega Retro 說，這些主機製造的年代，電容問題在電子產品中相當普遍，因此螢幕與音訊故障很常見。常見的症狀：

  • 喇叭聲音微弱或沒有聲音，但耳機正常：iFixit 指出這是電容故障。
  • 畫面非常暗：Dreamcast.nu 把這列為電容失效的症狀，而他們那台主機換上新電容後畫面就恢復了。
  • 換了新電容仍然昏暗或閃爍：問題可能出在背光燈管或其逆變器，所以「已換電容」的主機不一定完美。
  • 漏液：電容漏液可能損壞電路板上的焊墊，讓維修變得更困難。

買之前該檢查什麼？

從海外購買時無法親自測試，所以要詢問賣家，或仔細閱讀商品頁。如果你人在日本的店裡，就試一試。

  • 喇叭：音量開到最大時，喇叭要有聲音，不能只有耳機有聲音。
  • 螢幕：請賣家提供在正常照明的房間裡執行遊戲的照片。固定不動的線條通常是液晶或其驅動電路的問題，不是髒污。
  • 電池槽：請賣家提供6個電池槽的照片。白色或藍綠色的結晶表示舊電池漏過液。
  • 運作時間：詢問是否連續玩過5分鐘以上，因為有些故障要等機器變熱才會出現。
  • 電容：詢問是否更換過、何時更換、由誰更換。日文的說法是コンデンサ交換済み（電容已更換）。

日本的商品頁常常用短短幾個字說明故障。以下用語都出現在2026年10月31日駿河屋與 Buyee 的搜尋結果中：

日文意思
音声出力不可 / 音声出力不良沒有聲音／聲音有問題
通電不良 / 通電NG無法正常開機
通電OK / 通電確認済み可以開機。這並不代表遊戲能執行
動作未確認未測試
現状品現況出售
ジャンクJunk：現況出售，不保證能用

請把「未測試」當成「可能需要維修」。便宜的商品往往就是因為這樣才便宜。

哪種電源才安全？

最簡單的答案是電池。Game Gear 使用6顆 AA 電池，可運作大約3到5小時，因為背光無法關閉。這樣一來，主機就不會遇到任何電壓問題。

如果你想用插座供電，請買為你所在國家製造的電源轉接器。日本的市電是 100 V。日本的電源轉接器是 SA-150，額定輸入 100 V、輸出 9 V 850 mA。SEGA 的維修手冊依地區列出不同的電源轉接器：輸入 120 V、輸出 9 V，以及輸入 230/240 V、輸出 10 V。為 100 V 設計的電源轉接器，並不是為你家的插座設計的。在海外使用就需要降壓變壓器，所以盒裡附的電源轉接器通常沒有多大用處。

極性也要留意。RetroRegister 把 Game Gear 列為中心負極，但 iFixit 的一則回答卻要使用者確認是否為中心正極，所以我們不把任何一方當成事實。請閱讀主機電源插孔旁印的極性符號，並與電源轉接器上的符號對照。iFixit 警告，用錯電源轉接器可能損壞主機。日文維基百科說，日版主機官方可使用 Mark III、Master System 與 Mega Drive 的電源轉接器，海外版主機則可使用 Mega Drive 2 與 32X 的，所以兩者不能簡單地互換。

日版 Game Gear 的型號怎麼看？

SEGA 的兩份官方軟體清單顯示了其中的規律。SEGA 發行的遊戲使用 G- 加4位數字，例如 G-3405。授權廠商發行的遊戲使用 T- 加5或6位數字，例如 T-66017 或 T-143017。

依賴型號之前，有3點要注意：

  • 盒子上可能沒有。Phantasy Star Gaiden 在 SEGA 的清單上是 G-3405，但盒子上印的是 671-2246，卡帶標籤上是 670-2352。
  • 商店可能用另一組號碼。駿河屋把 Sylvan Tale（G-3426）歸在 670-6072 之下。
  • 許多遊戲在資料中沒有型號。2026年10月31日，Kataban 的196筆 Game Gear 資料中，33筆有 G- 型號，15筆有 T- 型號，148筆沒有。

如何在 Kataban 上找 Game Gear 遊戲？

先用標題搜尋，英文或日文都可以。Phantasy Star Gaiden 可以找到，有型號時用型號也行：T-66017 會找到 GG Aleste。每筆結果都會給你日文標題，這就是你要輸入到日本商店的文字。

如果其他版本混了進來，就在標題後加上機種名，例如 Sonic Game Gear。想瀏覽全部的話，就單獨搜尋 Game Gear：2026年10月31日的結果是全部196筆，每次顯示20筆。我們的文章都在 Game Gear 標籤頁。

從日本以外怎麼買？

常見的管道是駿河屋和 Buyee 這類代購服務。我們的不會日文也能買到日本復古遊戲指南說明了它們的運作方式。2026年10月31日，在 Buyee 搜尋 HGG-3210 有38筆商品，全部都是主機。
