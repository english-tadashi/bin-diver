《Rod Land》的紅白機版與 Game Boy 版：日版卡帶與它們的商品編號

2026-09-18

《Rod Land》最初是 Jaleco 在1990年4月推出的街機遊戲。兩個妖精 Tam 與 Rit 爬上一座塔去救出母親，用魔法杖抓住怪物，再把牠們摔在地上。它的家用版大多是歐洲的電腦版本。在日本，它兩度以任天堂卡帶推出——1992年12月的紅白機，以及1993年5月的 Game Boy——標題是《妖精物語ロッド・ランド》（Yōsei Monogatari Rod Land，直譯為「妖精故事 Rod Land」）。

今年要找這兩捲卡帶，很容易先撞上別的東西。2026年8月，紅白機版以下載版登上 Nintendo Switch；而從2024年起，市面上也有一捲全新的《Rod Land》Game Boy 卡帶。兩者都不是日版卡帶。本文整理這兩個日版各是什麼、和街機版差在哪，以及怎麼用商品編號找到每一捲：紅白機版是 JF-39，Game Boy 版是 DMG-RLJ。

Switch 版發售消息（日文）：Game Watch，2026年7月30日

  • 日文標題：妖精物語ロッド・ランド（Yōsei Monogatari Rod Land），發行商為 Jaleco（ジャレコ）
  • 紅白機：1992年12月11日 · 商品編號 JF-39 · 未稅 6,500円
  • Game Boy：1993年5月21日 · 商品編號 DMG-RLJ · 含稅 3,900円
  • 原作：Jaleco 的街機遊戲，1990年4月，僅在日本推出
  • 2026年8月6日起登上 Switch：City Connection 的ジャレコレ ファミコン編（Jaleco 合輯・紅白機篇）系列作品，990円——收錄紅白機版及其歐洲版，僅限下載
  • 不是日版 Game Boy 卡帶：透過 Strictly Limited Games 與 Limited Run Games 販售的2024年 Retro-Bit 收藏版，是歐洲英文版

《Rod Land》是什麼？日本推出了哪些版本？

街機版《Rod Land》由 Jaleco 開發並發行，根據英文維基百科，它「最初只在1990年4月於日本推出」。它沒有跳躍鍵：只能靠梯子移動，而且一次可以自己變出一道梯子。家用電腦版——Amiga、Atari ST、Commodore 64、Amstrad CPC、ZX Spectrum——以及 NES 版，都是由倫敦的工作室 The Sales Curve 製作，其中電腦版都是在歐洲推出。

日本則拿到了兩個任天堂版本，都由 Jaleco 發行：紅白機卡帶在1992年12月11日，Game Boy 卡帶在1993年5月21日。兩者當時都沒有在北美上架。維基百科說 NES 版「只在義大利、西班牙、荷蘭與日本推出」，而 Limited Run Games 則把自家2024年的 Game Boy 卡帶形容為這款遊戲「在北美的首次官方實體發行」。

紅白機版與 Game Boy 版和街機版有什麼不同？

兩者之中，紅白機版改動得比較多。英文維基百科特別點名它是「加入了一些新的平台關卡，並讓玩家可以跳躍」的版本。日文維基百科則把更動列得更詳細：

  • 沒有第二段故事。街機版在破完第一輪之後還有另一組30關；紅白機版沒有
  • 跳躍是一個選項。透過設定可以跳躍，還可以踩踏敵人，讓牠們暫時麻痺
  • 追加關卡。在其中兩場頭目戰之前，追加了縱向與橫向捲軸的關卡，另有一場頭目戰改在水中進行

維基百科沒有用同樣的方式點名 Game Boy 版；它記下的唯一差異，讓遊戲變得比較容易。街機版在爬梯子時不能攻擊；維基百科指出，在 Game Boy 版上「玩家就算在爬梯子時也能用魔杖攻擊敵人，讓遊戲稍微容易一些」。

Switch 版或新的 Game Boy 卡帶，是日版嗎？

Switch 版是紅白機遊戲——但不是卡帶。Game Watch 報導，City Connection 於2026年8月6日在 Nintendo Switch 推出ジャレコレ ファミコン編：妖精物語ロッド・ランド，售價 990円，是其紅白機系列的第八款作品。它是「2 in 1」：在標題畫面可以選擇原本的日版，或海外版《ROD LAND》，City Connection 稱後者為歐洲版。海外版加入了教學與更多選項設定，兩個版本都可以開日文字幕遊玩。City Connection 也把跳躍設定預設為開啟。香港的 Nintendo eShop 也以英文名稱《JALECOlle Famicom Ver. ROD LAND》上架；台灣是否能購買，我們未能確認。如果你想玩紅白機版《Rod Land》，這是最簡單的方法。如果你想擁有它，仍然得是1992年的卡帶——而紅白機卡帶需要紅白機：它是 60 針的基板，不加轉接器插不進 NES。

街機原作也要回來了。2026年7月公布、由 Gravity Game Arise（グラビティゲームアライズ）發行的 JALECO ARCADE COLLECTION Vol.2 收錄了街機版《Rod Land》（官方繁體中文網頁寫作「羅德海洋 (Rod Land)」）；官網列出的平台是 Steam、Nintendo Switch 與 PlayStation 5，Switch 與 PS5 另有實體版，發售日期為「預計於2026年冬季發售」——這是街機版，不是任何一捲日版卡帶。

新的 Game Boy 卡帶不是日版。2024年，Strictly Limited Games 與 Retro-Bit 接受了《Rod Land》Game Boy 收藏版的預購，北美則透過 Limited Run Games 販售。發行商的常見問題寫得很清楚：「Game Boy 版是歐洲英文版」，而且遊戲內的授權標示已經更新，「這一點反映在標題畫面上」。同一次發行也包含一捲 PAL 英文版的 NES 卡帶。它是一捲更新了授權標示的歐洲版新卡帶——不是日版 DMG-RLJ 卡帶。

商品編號是什麼？要怎麼用？

紅白機卡帶是 JF-39。兩份彼此獨立的目錄資料都這樣記載——日本遊戲資料庫ピコピコ大百科，以及 Hard-Off 的一則商品頁——而在駿河屋用 JF-39 做商品編號搜尋，只會回傳這款遊戲，沒有別的。

Game Boy 卡帶是 DMG-RLJ。Game Boy Database 把它列為外盒摺蓋、說明書與卡帶本身上的編號；在駿河屋用 DMG-RLJ 搜尋，同樣只回傳這款遊戲。如果打成帶國別後綴的完整寫法 DMG-RLJ-JPN，駿河屋什麼都查不到，所以請拿掉後綴。

兩組編號都不在 Kataban 目錄所依據的文化廳 Media Arts Database 裡。我們在2026年9月12日依據上述出處補上了這兩組編號，所以這兩捲卡帶的目錄卡片現在都會顯示它們。

用編號搜尋，結果也比用標題乾淨。2026年9月18日在駿河屋，編號搜尋回傳5筆紅白機版（其中2筆誤寫成ロットランド）與3筆 Game Boy 版，全部都是《Rod Land》。用標題 ロッドランド 搜尋則回傳25筆，其中7筆是街機基板。

現在能在哪裡買到日版卡帶？

駿河屋：我們查的那天，各有一件。2026年9月18日，駿河屋有一件紅白機版庫存，標為美品（近全新），¥13,900–¥33,200；還有一件 Game Boy 版，標為説明書不備（說明書不完整或有損），¥12,900–¥70,900。其他商品都已售完。駿河屋預設會隱藏售完的商品，所以如果下面的編號連結顯示0筆，代表那天沒有庫存，而不是商店沒有這款遊戲。

日本拍賣：用短名稱搜尋，再看標題。透過代購服務 Buyee 搜尋 ロッドランド，2026年9月18日回傳17筆：7筆紅白機卡帶、4筆 Game Boy 卡帶、1筆與其他遊戲合售的 Game Boy 組合、1片街機基板、2筆只有說明書、1張傳單，以及1筆只有外盒與說明書、不含卡帶。較長的寫法反而抓得少——妖精物語ロッド・ランド ファミリーコンピュータ（完整標題加上「ファミリーコンピュータ」）只回傳3筆，Game Boy 的對應寫法回傳2筆——因為賣家對這個名字有好幾種寫法。所以請用短名稱搜尋，出價前逐一確認標題：紅白機看ファミコン或FC，Game Boy 看ゲームボーイ或GB，並跳過説明書のみ（只有說明書）、基板（街機基板）、チラシ（傳單）與箱・説明書（只有外盒與說明書、不含卡帶——這與箱説付不同，後者指卡帶附外盒與說明書）。

eBay：適合找紅白機卡帶，不適合找日版 Game Boy 卡帶。搜尋 Rod Land famicom（2026年9月18日從日本實測）回傳9筆完全符合的結果，全部標為紅白機版《Rod Land》。Rod Land game boy 回傳36筆，前12筆中有7筆是 Retro-Bit 版、4筆是歐洲版卡帶，還有1筆是歐洲版的說明書單品。套用 eBay 的區域代碼 NTSC-J（日本）篩選後，完全沒有日版《Rod Land》Game Boy 的商品。要找日版 Game Boy 卡帶，請用駿河屋或 Buyee。

為什麼要在 Kataban 用日文搜尋？

因為英文名稱只找得到兩捲卡帶中的一捲。目錄只在 Game Boy 那一筆存了英文標題《Rod Land》，而紅白機那一筆的讀音是一個連在一起的單字。所以在 Kataban 搜尋 Rod Land，會回傳 Game Boy 卡帶，卻漏掉紅白機那一捲。ロッドランド則會回傳兩者，各自附上商品編號、發售日，以及在日本貨架上該找的假名（ヨ，在や行）。JF-39 或 DMG-RLJ 則會直接帶你到其中一捲。
