《Royal Stone》：《Crystal Warriors》只在日本發售的 Game Gear 續作，以及讓完整品真正完整的那張地圖

2026-10-11

  • Game Gear
  • 戰略・戰棋
  • 1990年代
  • 世嘉
  • 日本限定

《Royal Stone》——全名ロイアルストーン 開かれし時の扉，大意是「Royal Stone：被開啟的時之門」——於1995年2月24日在日本以 Game Gear 卡帶發售，未稅 4,800円。它是一款回合制戰略 RPG，也是《Crystal Warriors》的續作，而《Crystal Warriors》是 SEGA 確實帶到北美與歐洲的 Game Gear 遊戲之一。這一款則從未離開日本。它沒有官方英文標題：日文標題是「Royal Stone」的片假名拼寫，本文就用這個名字。

這是「始終沒有續作」這個系列的一篇，而這一篇從另一邊切入這個主題：它本身就是續作。《Crystal Warriors》等到了它的續作；續作卻什麼都沒等到，這條線也就停在它這裡。

這也是數字終於守規矩的一篇。四個來源的定價一致；在《Sylvan Tale》打破規則之後，商品編號又能在商店裡找到遊戲了；而完整的日文標題，在我們查的兩家店都只回傳這款遊戲。

  • 日文標題：ロイアルストーン 開かれし時の扉（媒體藝術資料庫與 Sega Retro 寫成帶中點的ロイアル・ストーン）。由 Sega CS5 開發、SEGA 發行
  • Game Gear 卡帶：1995年2月24日 · 未稅 4,800円 · 4 Mbit · 單人
  • 商品編號：G-3425，出自 SEGA 自家的軟體清單與 Sega Retro。媒體藝術資料庫那一筆沒有商品編號
  • 系譜：《Crystal Warriors》（1991年）的續作，原創角色設計掛名九月姫（Kugatsuhime），也就是為前作設計角色的人
  • 只在日本：《Crystal Warriors》曾在北美與歐洲發售；《Royal Stone》則從未在其他任何地方發售
  • 再發售：《Crystal Warriors》在2013年回到了 Nintendo 3DS 虛擬主機。《Royal Stone》從未單獨再發售——只有2020年黑色 Game Gear Micro 裡的一個位置
  • 要買的話：兩家店都搜完整標題ロイアルストーン 開かれし時の扉。2026年9月21日，駿河屋有一捲近全新的現貨 ￥5,900，以及市集十七捲，從 ￥4,540 起

《Royal Stone》是什麼？和《Crystal Warriors》是什麼關係？

先從第一款說起。《Crystal Warriors》——在日本叫アーリエル クリスタル伝説——1991年12月13日在日本發售，1992年在北美與歐洲發售。日文維基百科把它描述為一款回合制戰略遊戲，關卡之間帶有角色扮演要素：每場戰鬥後可以招募同伴、購買裝備。你扮演 Ariel 王國的公主 Eris（歐美版為 Arliel 的公主 Iris），對抗 Gark 帝國的魔法師 Gram（歐美版為 Jyn 與皇帝 Grym），他的目標是第四顆水晶。每個單位都有屬性，每種屬性都有弱點。英文維基百科把它比作《Fire Emblem》與《光明與黑暗》（Shining Force）系列。

《Royal Stone》是同一類的遊戲。SEGA 自家的軟體清單把兩款都歸在シミュレーション底下，Sega Retro 則稱《Royal Stone》為「a turn-based strategy/RPG」與「a sequel to Crystal Warriors」。英文維基百科的《Crystal Warriors》條目用一句話說了同樣的事：「A Japan-only sequel Royal Stone was published in 1995.」

兩款之間最清楚的那條線是畫師。Sega Retro 轉錄的《Royal Stone》遊戲內製作名單，最後一行是「Original Character Design by: Kugatsuhime」——而九月姫正是日文維基百科為《Crystal Warriors》記載的角色設計。同樣的類型、同樣的設計師、同樣的主機，相隔三年。

它不是一段能用文件證明的劇情延續。標題裡沒有數字，也沒有 Ariel。主角也不同：Sega Retro 描述《Royal Stone》的主角是蒙受污名的騎士 Eva，她因莫須有的罪名被定罪，遭她效忠過的王國放逐，一路結交同伴，設法洗清自己的名譽。那不是 Eris（歐美版的 Iris）。我們讀過的來源沒有一個把兩個故事串在一起，所以請把它當成系譜上的續作，而不是同一段劇情的第二部。

製作名單裡還有一個名字值得一看。總監是 Katsuhiro Hasegawa，而英文維基百科把一位 Katsuhiro Hasegawa 列為《Sylvan Tale》的兩位總監之一，也就是本系列的上一款。兩款都是 Sega CS5 的作品，發售只差四週：《Sylvan Tale》在1995年1月27日，《Royal Stone》在2月24日。

日版卡帶是哪一版？編號是多少？

卡帶只有一種，而這一次它只有一組號碼。

SEGA 自家的 Game Gear 軟體清單給出的那一行是 2月24日 | ロイアルストーン 開かれし時の扉 | シミュレーション | 4,800円 | G-3425 | 4M，Sega Retro 的發售表在日本欄位給的也是 G-3425，日期與價格相同。這是同一組編號的兩份獨立紀錄。

文化廳媒體藝術資料庫把這捲卡帶記為 M758903，有日期、發行商與 4800円 (税抜)，但沒有 schema:productID，也沒有條碼。所以政府的紀錄——也就是 Kataban 目錄的來源——完全沒有這組編號。我們在2026年9月21日根據上面兩個來源，把 G-3425 補進了 Kataban 目錄。

SEGA 的清單有一個怪處：這一段的編號不是按發售順序給的。G-3425 給了1995年2月的《Royal Stone》，G-3426 卻給了早一個月發售的《Sylvan Tale》。再往上看，G-3424（魔導物語 Ⅲ 究極女王様）在1994年11月25日發售，比 G-3423（魔法騎士レイアース）早了三週。如果你看到編號與日期順序對不上，那是 SEGA 的編法，不是誤植。

在《Sylvan Tale》之後，好消息是：駿河屋用商品編號為這捲卡帶建了索引。在那裡搜 G3425 會回傳本作——那一捲現貨——而顯示缺貨商品後是8筆，其中5筆是本作。另外3筆是一款東京フレンドパークII、一款SDガンダム外伝 IV，以及一本《忍者龜》的說明書。所以編號管用，但會拖進雜訊，標題則不會。

中點在實際上沒有影響。SEGA 的清單寫ロイアルストーン，不帶中點；媒體藝術資料庫與 Sega Retro 寫ロイアル・ストーン；而兩家店與 Kataban 不論哪種寫法都會回傳本作。

當年定價多少？現在要多少？

四個來源說法一致：媒體藝術資料庫記的是 4800円 (税抜)，SEGA 的軟體清單印的是 4,800円，Sega Retro 給的是 ¥4,800，駿河屋的定価欄寫的是 ￥5,280——也就是 4,800円 加上今天10%的消費稅。所以定價是未稅 4,800円。

如果那個 ￥5,280 看起來眼熟，那是因為它上一篇出現在不對的地方：駿河屋在《Sylvan Tale》的頁面上也顯示同一個數字，而在那裡它對不上。在這裡，在它真正所屬的遊戲上，它對得上。

接下來是市場。2026年9月21日，駿河屋有一捲現貨：

  • 近全新（美品）：￥5,900
  • 另有市集一行，￥4,540，共十七捲二手

其他條目全部缺貨。這讓它和《Sylvan Tale》並排——2026年9月21日《Sylvan Tale》的完整品是 ￥6,000——所以這兩款1995年初的 Sega CS5 遊戲，今天的價格也幾乎一樣。市集是比較便宜的路線，大約便宜 ￥1,400；店家自己那捲則是評為近全新的那一捲。

那張地圖是什麼？為什麼對完整品很重要？

這是這款遊戲留給收藏者的細節。《Royal Stone》的盒子裡附了一張紙地圖，少了它，完整品就算不上真正完整。

從商店怎麼分級就看得出來。駿河屋的8個條目裡，有一個是…(状態：MAP欠品)——「狀態：缺地圖」。這家店把缺地圖當成一項獨立的狀態瑕疵，和外盒或說明書受損分開。賣家也知道這件事：在 Buyee 上，有一筆商品標榜箱説マップはがきつき——附外盒、說明書、地圖與明信片。

我們無法告訴你沒有地圖的卡帶會便宜多少。我們查的那天，缺地圖的那個條目已經缺貨，而這家店不顯示缺貨商品的價格。我們能告訴你的是該看什麼。在日本的商品頁上，下標前先在文字或照片裡找マップ或MAP。如果商品頁只寫箱説（外盒與說明書），就當作地圖不在裡面。

為什麼沒有續作？

紀錄裡沒有任何解釋。英文維基百科的《Crystal Warriors》條目點出《Royal Stone》是續作，此後再無其他。媒體藝術資料庫上《Royal Stone》正好只有一筆：1995年的卡帶。相較之下，《Crystal Warriors》還有第二筆，是2013年的 Nintendo 3DS 版，SEGA 自家的軟體清單也把它標為▶3DS。《Royal Stone》沒有這個標記。

我們查了 SEGA 悄悄讓舊作續命的那兩個下載服務——Sonic Cafe（2001年起的 i-mode 訂閱服務）與 ゲーム図書館（1990年11月起、透過 Mega Modem 發行三十九款的服務）。兩份完整清單裡都沒有 Royal、Stone、Ariel 或 Warriors。裡面唯一的 Crystal 是《Dragon Crystal》，那是另一款遊戲。

真正發生的，是和《Sylvan Tale》同樣的一件小事。2020年10月6日，SEGA 推出了 Game Gear Micro，一台鑰匙圈大小的主機，共四種顏色、每色內建四款遊戲，而《Royal Stone》是黑色款的四款之一，和《音速小子》（Sonic the Hedgehog）、《魔法氣泡通》與《Out Run》並列。日文維基百科表示，收錄陣容主要由 SEGA 的 Yosuke Okunari 選定，參考了當年的銷量、雜誌排行，以及先前 Nintendo 3DS 虛擬主機版推出時的反應。結果是一個小小的反轉：有過 3DS 版的《Crystal Warriors》不在四款主機的任何一款裡，而從未有過 3DS 版的續作卻在。

今天買得到嗎？該買哪一捲？

買得到。只要把缺貨商品也顯示出來，駿河屋一共有8個不同的條目，其中一個有現貨（2026年9月21日的價格）：

  • ロイアルストーン 開かれし時の扉（美品）——近全新，現貨 ￥5,900，市集十七捲從 ￥4,540 起
  • …(箱説なし)——只有卡帶。缺貨
  • …(状態：ROMカセットのみ、ROMカセット状態難)——狀況差的裸卡帶。缺貨
  • …(状態：説明書状態難)——完整，但說明書狀況差。缺貨
  • …(状態：MAP欠品)——除了地圖之外都齊全。缺貨
  • ランクB)…——店家的B級。缺貨
  • [説明書のみ]…——只有說明書。缺貨
  • [外箱のみ]…——只有外盒。缺貨

最後兩個不是遊戲。請讀標題最前面的中括號：説明書のみ是說明書，外箱のみ是外盒。

在 Buyee，2026年9月21日用完整標題搜到4筆，其中4筆是本作（2026年9月21日的明細：2筆附外盒、說明書與明信片，1筆只附說明書，1筆沒有列出任何附件）。

這裡沒有海外版的問題。這款遊戲從未在日本以外發售，所以沒有要過濾掉的西方卡帶，用日文標題搜到的東西也不會是錯的地區版。

兩家店各要怎麼搜？

兩家店要的是同一組詞：完整標題ロイアルストーン 開かれし時の扉。

駿河屋：打標題，而且它很寬容。完整標題現貨回傳1筆、顯示缺貨後8筆，8筆全是本作。短標題ロイアルストーン回傳同樣8筆。這家店也會吸收最可能的錯字：用一般ヤ的ロイヤルストーン也回傳同樣8筆。商品編號是次佳的路線，如上所述——G3425 找到8筆中的5筆，另外3筆無關。帶連字號的 G-3425 沒有用：它回傳一大堆無關的遊戲，從ドンキーコングGB到《Raidou Remastered》。英文標題回傳0筆。

Buyee：完整標題最乾淨。ロイアルストーン 開かれし時の扉回傳4筆，其中4筆是本作。短標題ロイアルストーン回傳15筆，其中6筆是本作、1筆是黑色 Game Gear Micro；其餘大多是一個叫 ROIAL 的品牌的服裝，以及寶石。帶中點的ロイアル・ストーン回傳7筆，其中6筆是本作、1筆是 Game Gear Micro。加上機種名的ロイアルストーン ゲームギア回傳6筆，其中6筆是本作或主機。

Buyee 不會吸收這個錯字。ロイヤルストーン回傳6,226筆皇家藍的藍寶石與月光石——而埋在其中的，是一捲賣家用這種寫法登錄的本作。用正確寫法搜，那一捲永遠不會出現。如果你有耐心，值得再用ヤ搜一次。

在 Buyee，編號與英文標題都不管用。G-3425 回傳9筆，其中一筆是本作；其餘包括汽車芳香劑與一本寶可夢攻略本。G3425 回傳396筆，前三十筆沒有一筆是本作。Royal Stone 回傳6,489筆戒指、手環，以及一組名字真的叫「Royal Stone」的杯子——前三十筆也沒有一筆是本作。

這一款為什麼要用 Kataban 搜？

因為這是唯一一個「日文標題（不論有沒有中點）與商品編號都落在這捲卡帶上、而且只落在它身上」的地方。

2026年9月21日在桌機瀏覽器上確認：ロイアルストーン、ロイアル・ストーン與完整標題各回傳這捲卡帶。G-3425 與 G3425 也一樣——各一筆，完全沒有編號在駿河屋拖進來的雜訊——因為我們在2026年9月21日把 SEGA 清單上的編號補了進去；在那之前兩者都回傳0筆，因為媒體藝術資料庫這一筆沒有商品編號。有一件事不管用，值得說清楚：Royal Stone 回傳零筆，因為目錄這一筆沒有英文標題。在日本店裡，要翻的假名是ロ。

那《Crystal Warriors》呢？

它是今天比較容易玩到的那一款，也落在這份購買指南之外，但不提它反而奇怪。

《Crystal Warriors》在1992年有過英文版發售，2013年回到了 Nintendo 3DS 虛擬主機。原版卡帶是另一條路：日版アーリエル クリスタル伝説在 SEGA 的清單上是商品編號 G-3403，也是清單上標著▶3DS的那一筆。

如果你想把這一對擺上架，那就是兩捲相隔三年、由同一位畫師繪製的日版卡帶。只有第一款曾經有過英文版。

一款只在日本發售的戰略 RPG，是一款確實發行到西方的遊戲的續作，由同一位畫師繪製，總監的名字也出現在《Sylvan Tale》上。它沒有自己的續作、沒有移植、也沒有在地化——只有二十五年後，成為黑色 Game Gear Micro 內建的四款遊戲之一。如果你要買，請確認盒子裡有地圖。
