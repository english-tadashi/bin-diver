Shinyaku DoDonPachi Dai-Fukkatsu Just Launched — Here's Where the Series Came From

2026-08-28

CAVE released Shinyaku DoDonPachi Dai-Fukkatsu (新約・怒首領蜂大復活, subtitled Reignite) on Steam on August 27, refining the 2008 arcade original with new stages, characters, and a 10-player "Danmaku Battle Mode: Royale" — the first time a bullet-hell shooter has shipped online multiplayer at that scale. If the new release has you curious about where this series started, here are the four home releases that trace its history.

CAVE's launch trailer is up on the game's official YouTube channel, and the team posted about the release on X.

Three of the four are ordinary secondhand discs in Japan, findable by the product code printed on the spine. The Saturn one is the exception, and it is worth explaining why.

DODONPACHI (PlayStation, 1998)

怒首領蜂 · PlayStation · 1998 · SPS · product code SLPS 01364

This is where the series proper begins — DoDonPachi is the 1997 arcade sequel to DonPachi, and the game that turned CAVE's screen-filling bullet patterns into the thing the studio would be known for. Getting that onto a PlayStation was not a straightforward port. The PS1 was built around textured 3D polygons, not the fast 2D sprite blitting an arcade shooter lives on, and a screen carrying several hundred individually-tracked bullets is exactly the workload that hardware was worst suited to. The home version reproduces the arcade layouts and the scoring chain intact, but it does it by giving ground elsewhere — on how much the machine will draw in a single frame, and on how steadily it holds its rate when a boss opens up. Play it now and the compromises are legible, which is its own kind of interest: this is the disc that had to prove a danmaku shooter could live on a home console at all.

DODONPACHI (Sega Saturn, 1997)

怒首領蜂 · Sega Saturn · 1997 · no product code on record

The Saturn version arrived first, and it is the more interesting of the two home conversions because it does not stop at reproducing the coin-op. Alongside an Arcade Mode built from the arcade original, the disc carries a Saturn Mode — a second pass through the game with stage layouts and enemy placement reworked specifically for this release, so it is not simply the same six stages with a different label on the menu. The Saturn's twin-VDP setup was genuinely strong at 2D, which is why CAVE's patterns had somewhere to go here that they did not have on the PlayStation. If you only play one of the two 1990s conversions, the argument for this one is that it contains material that exists nowhere else in the series.

A note on finding it: Kataban has this release in its catalog, but the source data carries no product code for it — the field is empty, so there is no code to search a shop by, and no by-code buy link to give you. Search it by its Japanese name instead: 怒首領蜂. That is also the name to type into a Japanese shop's search box.

DODONPACHI DAI-OU-JOU (PlayStation 2, 2003)

怒首領蜂 大往生 · PlayStation 2 · 2003 · Arika · product code SLPS 25233

Dai-Ou-Jou is the entry that settled the series' reputation. It is the one that formalised the hyper system and the two-shot-type split into a scoring game people were still arguing about a decade later, and the one whose true final boss became shorthand for how far a bullet-hell game would go. It also matters because it never stopped being the reference point: the 2023 Dai-Ou-Jou Rinne Tensei — itself on Switch and PS4, and also in Kataban's catalog — is built directly on this game, and its title is a straight continuation of this one. If you want the version of DoDonPachi that later CAVE releases keep being measured against, it is this PS2 disc, and unlike the 1990s conversions it had a machine capable of holding the arcade game's frame rate.

DODONPACHI DAI-FUKKATSU VER1.5 (Xbox 360, 2012)

怒首領蜂 大復活 Ver1.5 · Xbox 360 · 2012 · CAVE · product code F6G00004

This is the one that connects directly to yesterday's news. Dai-Fukkatsu is the 2008 arcade game — released in the West as DoDonPachi Resurrection — and this Xbox 360 disc is its home conversion, carrying the Ver1.5 revision of the arcade board along with the extra modes CAVE built for the console release. Shinyaku DoDonPachi Dai-Fukkatsu, out on Steam since August 27, is a new pass over this exact game: same 2008 original underneath, now with added stages, added characters, and the 10-player Royale mode on top. So of the four discs here, this is the one where you can put the old version and the new version side by side and see precisely what CAVE changed. Kataban lists it under the English title Dodonpachi Resurrection, which is what the eBay listings will call it too.

From Cabinet to Steam Lobby

Four releases, four machines, fifteen years: a Saturn in 1997, a PlayStation in 1998, a PlayStation 2 in 2003, an Xbox 360 in 2012 — each one a different answer to the same question of how you fit an arcade cabinet into a living room, and each one giving up something different to do it. What ties them together is that the game itself never really changed shape; the hardware underneath it did, until it could finally keep up. Now the newest version adds something none of those four could have carried — nine other people in the same room of bullets. That is a good reason to go back through the discs and see where the patterns you are dodging online were first drawn.
