Ax Battler on Game Gear: Sega’s 1991 Golden Axe Spin-Off, and the Catalogue Number Sega’s Own List Gets Wrong

2026-10-07

  • Game Gear
  • RPG
  • 1990s
  • Sega
  • Golden Axe

Ax Battler: A Legend of Golden Axe went on sale in Japan on 1 November 1991 as a Game Gear cartridge at 3,800円 before tax, with アックスバトラー ゴールデンアックス伝説 on the spine. Aspect Co. developed it, Sega published it, and it is the only Golden Axe game built for a handheld.

This is an entry in a series about games that never got a second part, and Ax Battler is an odd one, because the brand it belongs to got three more. Golden Axe carried on as a brawler on the Mega Drive and then as a fighting game on the Saturn. The top-down, random-encounter, password-saving thing Aspect built for the Game Gear was tried once and never again.

There is also a documentation problem attached to this cartridge, and it is why this guide leads with the code. Sega’s own software list gives Ax Battler the wrong catalogue number.

  • Japanese title: アックスバトラー ゴールデンアックス伝説, developed by Aspect Co., published by Sega
  • Game Gear cartridge: 1 November 1991 · 3,800円 before tax · 2 megabits · one player
  • Catalogue number: G-3304 — not the G-3306 in Sega’s official list, which is a typo
  • Three games in one: a top-view overworld with random encounters, towns with shops, and a side-scrolling beat ’em up whenever a fight starts
  • Also released abroad: North America March 1992 and PAL 1992, so overseas cartridges exist
  • No second part: the brand continued without it, and the game has never been re-released — no Virtual Console, no download service
  • Buying it: search アックスバトラー at both shops. Suruga-ya’s own copy was ￥12,100 while a marketplace seller on the same page had one at ￥2,830 (prices as of 21 September 2026)

What is Ax Battler, and how does it play?

You play the barbarian from the first Golden Axe. English Wikipedia sets up the story: Death Adder steals the Golden Axe — “a magical weapon that grants its wielder unimaginable power” — from Firewood Castle, and the king sends his strongest warrior after it, across ten named landmarks from the Spooky Cave to Death Adder’s Castle.

The structure is not what the name leads you to expect. Wikipedia splits the game into three modes. A map scene “shows the player’s movements in a top-view overworld as he moves across the wilderness”, where “enemies randomly attack”. A town scene looks the same but lets you talk to NPCs and visit stores. And the action screen, which the game switches to “when the player encounters an enemy or enters one of the special landmarks”, is “a side-scrolling beat ’em up/platform environment”.

So the Golden Axe you know is in there, but as the combat layer of a small role-playing game wrapped around it. You walk a world map, something jumps you, the screen becomes a brawler, and then you are back on the map. It is closer in shape to a console RPG of 1991 than to the arcade game the character came from.

One object ties the economy together. Magic vases “can be used for his magical attacks or as currency in the towns”, so every vase is a decision between casting it and spending it. New attacks are taught at Training Houses rather than found. And there is no battery: you collect passwords from towns, and the passwords are the save system.

Which release is the Japanese cartridge, and what is its code?

The Media Arts Database has the cartridge as row M744899: アックス=バトラー ゴールデンアックス伝説, Game Gear, published 1991-11-01 by 株式会社セガ・エンタープライゼス, two megabits, one player, 3800円 (税抜). What it does not have is a catalogue number — no schema:productID, no schema:gtin — which is normal for Game Gear rows there.

The usual second source is Sega’s own ソフトウェア一覧 for the Game Gear, which prints date, title, genre, price, catalogue number and ROM size in one row. That page now returns 403, so we read the Internet Archive’s capture of 23 February 2024. It gives Ax Battler this row:

11月 1日 | アックスバトラー ゴールデンアックス伝説 | ロールプレイング | 3,800円 | G-3306 | 2M

And seven weeks later in the same table:

12月20日 | ドナルドダックのラッキーダイム | アクション | 3,800円 | G-3306 | 2M

The same catalogue number on two different games. We parsed all 135 rows to rule out our own reading, and the result is specific: G-3306 is the only number in the list that appears twice, and G-3304 is missing from it entirely. One duplicate and one gap is what a transcription slip looks like.

To settle it we used a shop that indexes catalogue numbers as a field. Searching Suruga-ya across the gap: G3303 returns クニちゃんのゲーム天国, G3307 returns ソニック・ザ・ヘッジホッグ and G3308 returns モンスターワールド2 — all matching Sega’s list. G3306 returns ドナルドダックのラッキーダイム, and only that. And G3304, the number Sega’s list never uses, returns Ax Battler. Suruga-ya’s trade-in page for the game prints a 型番 field, and it reads G-3304.

So the code on the Japanese cartridge is G-3304, confirmed two ways, and G-3306 belongs to The Lucky Dime Caper starring Donald Duck. If you see G-3306 attached to Ax Battler anywhere — and you will, because Sega’s own page says it — that is where it came from.

The title has three spellings, too. The Media Arts Database uses an equals sign, アックス=バトラー; Sega’s list uses a space; Suruga-ya has stock filed with a full stop, アックスバトラー.ゴールデンアックス伝説. It matters less than it sounds, because all three land on the same results.

What was the list price, and what does it cost now?

The list price is the one thing every source agrees on. The Media Arts Database records 3800円 (税抜), and Sega’s list prints 3,800円 in the same row as the bad catalogue number. Suruga-ya shows 定価：￥4,180, which is that figure carrying today’s 10% consumption tax: 3,800 × 1.1 = 4,180. The number to quote is 3,800円 before tax.

What it costs now is the most practical thing in this guide. On 21 September 2026 Suruga-ya had exactly one copy in stock. The shop’s price on it was ￥12,100, and on the same page, one line below, the marketplace read ￥2,830 across five used copies (prices as of 21 September 2026).

That is a gap of ￥9,270, and the cheaper number is about a quarter of the dearer one. We have measured the same pair on the other Game Gear games in this series and the marketplace has been cheaper every time, but never like this: Royal Stone was ￥5,900 against ￥4,540 (prices as of 21 September 2026). Here the two numbers are not in the same bracket.

Read the whole page before you add anything to a cart. The shop’s own copy carries Suruga-ya’s grading and Suruga-ya’s returns, which is worth something. A four-times premium is a lot to pay without knowing you are paying it.

Was Ax Battler actually any good?

Opinion was split, and it stayed split. It would be easy to tell a no-sequel story as an injustice; the contemporary reviews do not support that version.

The magazines that liked it liked it a lot. Zero gave 87/100 and, as Wikipedia summarises, “proclaimed that Ax Battler successfully expanded on the premise of the original games and called it a ‘surefire winner’”. MegaZone gave 78/100, Sega Pro 77/100. Mean Machines Sega gave 39% and did not soften it: the beat ’em up part was “extremely poor”, the quest “dull and uninspiring”, and playing it was like jumping off a cliff — “one go is more than enough, and isn’t really recommended at all”.

Japanese coverage ran cooler than the British high scores. Beep! Mega Drive scored it 5.25/10 in the month it came out. Famitsu’s four reviewers gave 5, 5, 5 and 4 out of 10. When Sega Saturn Magazine polled its readers in 1995, Ax Battler came back at 4.5937 out of 10, 125th among Game Gear titles.

That is the picture: a spin-off some reviewers thought stretched the brand somewhere interesting, and others thought was a bad brawler with map screens in between. What is not in dispute is that the shape Aspect built — overworld, random encounters, brawler combat, password saves — is one Golden Axe never used again.

Why was there never a second Ax Battler?

Not for lack of a series. The Media Arts Database has the rows: ゴールデンアックス2 on Mega Drive in 1991, GOLDEN AXE 3 on Mega Drive in 1993 as G-4093, and ゴールデンアックス・ザ・デュエル on Saturn in 1995 as GS-9041 — that last a one-on-one fighting game rather than a brawler.

None of those is a second Ax Battler. They continue the arcade game the character came from, not the Game Gear game he headlined. The handheld branch produced exactly one game.

It never came back in any other form either. We checked both Sega download services where the company quietly kept older properties alive, and it is on neither: not in the title list for Sonic Cafe, the i-mode subscription service Sega ran from 2001, and not among the thirty-nine titles distributed through Game Toshokan, the Mega Modem service that launched in November 1990. The Media Arts Database has one row for this game and no Virtual Console row beside it — unlike Dragon Crystal and Defenders of Oasis, which both returned on the Nintendo 3DS in 2012.

So the cartridge is the game. No download, no compilation, no later port to buy instead.

Can you buy it today, and which copy should you buy?

Yes, and more easily than most games in this series. On 21 September 2026 Suruga-ya had one copy in stock plus five on its marketplace, and the Buyee search showed results: 5.

Suruga-ya holds five distinct entries once you show sold-out items, and the differences between them are the whole decision:

  • アックスバトラー ゴールデンアックス伝説 — the complete one, in stock at ￥12,100, with marketplace copies from ￥2,830 (prices as of 21 September 2026)
  • …(状態：箱(内箱含む)状態難) — complete, but the box is in poor condition. Sold out
  • …(箱説なし) — cartridge only, no box or manual. Sold out
  • [説明書のみ]… — the manual on its own. Sold out
  • [外箱のみ]… — the outer box on its own. Sold out

The last two are not games. They exist so someone rebuilding an incomplete copy can buy the missing piece, and in a results list they look like cheap listings of the cartridge. Read the bracket at the front: 説明書のみ is a manual, 外箱のみ is a box.

On Buyee the search showed results: 5 (single cartridges: 4; multi-game lot: 1). The lot pairs this one with Batman Forever and Kishin Douji Zenki, so its price is not the price of this game. Remember too that overseas cartridges exist — the game shipped in North America and PAL territories in 1992 — and Japanese shops label those 海外版. None turned up in our measurements, but those were taken on one day.

How do you search each shop for it?

Both shops want the same words: アックスバトラー. That is unusual. For most games in this series the two sites need different inputs.

Suruga-ya: the title beats the code. アックスバトラー returns one listing in stock and five with sold-out items shown, and all five are this game. So do the full title, the subtitle alone, and the equals-sign spelling — the shop absorbs the punctuation. The catalogue number is clean but narrow: G3304 without the hyphen returns two with sold-out shown, both this game, but misses the box-only, manual-only and cartridge-only entries, which are filed without a code. G-3304 with the hyphen is useless — 140 listings in stock, 357 with sold-out shown, none of them this game on the first page, because Suruga-ya splits the code at the hyphen and matches the fragments.

Suruga-ya: do not search the series name. ゴールデンアックス alone returns 18 in stock and 107 with sold-out shown, of which exactly one is this game. The rest are Mega Drive originals, Golden Axe II and Golden Axe III, Golden Axe: The Duel on Saturn, arcade boards and a Sega Ages disc.

Buyee: the plain title, nothing added. アックスバトラー shows results: 5 (single copies: 4; lot: 1) — and nothing unrelated at all. This is the one place our usual advice inverts: adding the platform word makes it worse. アックスバトラー ゲームギア shows results: 4 (single copies: 3; lot: 1), because sellers who wrote GG or nothing drop out. The plain title finds more listings and gives up no precision.

Buyee: the English title returns nothing whatsoever. Ax Battler is not a flood of irrelevant results — it is zero listings. Japanese sellers write the Japanese name, and Buyee searches their free text. The series name is the opposite failure: ゴールデンアックス returns 293, of which one in the first thirty is this game, the rest Mega Drive cartridges, Saturn discs, built-in-game consoles and a Tyris Flare figure.

Neither shop wants the code. On Buyee the search for G-3304 showed results: 7 (this game: 0), while G3304 returns 503 with none in the first thirty. Buyee has no catalogue-number field; it is matching those characters inside seller-written titles, and G3304 turns up in car parts, postcards and coat listings.

Why search Kataban for this one?

Because three spellings of the title exist and you will meet all of them. Kataban strips punctuation before it matches, so whichever one you have does not decide whether you find the game.

The English title is a way in here, which is not true of every game in this series: the catalogue row carries Ax Battler: A Legend of Golden Axe, so an English search reaches the Japanese cartridge — something Buyee cannot do with the same words. On a Japanese shop shelf the kana to look under is ア. The row carries the code as well, although the Media Arts Database has no catalogue number for any Game Gear row: the correct one, G-3304, was recovered from a shop’s 型番 field and added to the catalogue, so G-3304 and G3304 both reach the cartridge.

A brand can outlive one of its own games. Golden Axe got three more entries and a fighting game; the handheld experiment with the world map and the password screen got none, and never came back on any service. If you want it, it is a 1991 cartridge with G-3304 on the label — whatever Sega’s list says — and it is cheaper than the first price you will be shown.
