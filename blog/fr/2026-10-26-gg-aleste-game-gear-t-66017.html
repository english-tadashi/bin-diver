GG Aleste sur Game Gear : le shoot-’em-up de Compile, et la fiche de base de données qui appartient à un autre jeu

2026-10-26

  • Game Gear
  • Shoot'em up
  • Années 1990
  • Sega
  • Uniquement au Japon

GG Aleste — GGアレスタ — est un shoot-’em-up à défilement vertical, développé et édité par Compile pour la Game Gear, licencié via le programme tiers de Sega. Les propres documents de Sega datent la sortie du 29 décembre 1991, au prix de 4 800円 hors taxes — même si, comme détaillé plus bas, cette date est moins sûre qu'il n'y paraît.

C'est le cas de code produit le plus embrouillé de ce catalogue à ce jour. La Media Arts Database du Japon ne compte qu'une seule ligne pour GG Aleste — et la plateforme, le code produit et le code-barres de cette ligne appartiennent à une autre cartouche : le shoot-’em-up Sega Mark III de 1988, une génération de console entièrement différente. Le vrai code du jeu Game Gear a dû être confirmé indépendamment, via trois autres sources.

  • Titre japonais : GGアレスタ. Développé et édité par Compile, licencié via le programme tiers de Sega (il figure sur la liste des éditeurs tiers de Sega, pas sur sa propre liste de titres maison)
  • Cartouche Game Gear : prix 4 800円 hors taxes · shoot-’em-up à défilement vertical · troisième jeu de la série Aleste de Compile
  • Code produit : T-66017, confirmé indépendamment par la propre liste logicielle sous licence de Sega, la fiche produit de Suruga-ya et la base de données matérielle de SMS Power!. La fiche de la Media Arts Database (M726876) porte à la place G-1352 et le code-barres 4974365143527 — tous deux appartenant à la cartouche Sega Mark III de 1988, pas à ce jeu
  • Date de sortie : non résolue. La liste des éditeurs tiers de Sega indique 1991年12月29日 ; SMS Power! indique le 20 décembre 1991 ; les fiches produit de Suruga-ya (les deux vérifiées) indiquent 1991/11/29. Nous retenons ci-dessous la date de Sega comme référence principale, mais aucune des trois sources ne s'accorde exactement avec les deux autres
  • Attention aux suites : une recherche sur le simple titre est diluée par GG Aleste II, GG Aleste 3 (une sortie PS4/Switch exclusive au Japon de 2020) et les produits dérivés de l'Aleste Collection de 2020
  • Où l'acheter : le code produit T66017 (sans trait d'union) est la voie la plus propre chez Suruga-ya ; chez Buyee, utilisez le titre japonais puis filtrez les suites à la main

Qu'est-ce que GG Aleste, et où se situe-t-il dans la série Aleste ?

Aleste a débuté en 1988 sur MSX2, par Compile — le studio derrière la série Puyo Puyo et une longue liste de shoot-’em-up. La même année, Compile l'a porté sous le même titre sobre, アレスタ, sur la console 8 bits Mark III de Sega. GG Aleste, trois ans plus tard, est le saut de la série vers la portable couleur de Sega : un shooter vertical rapide doté du système d'amélioration d'armes caractéristique de la série, Compile étant crédité comme développeur et éditeur, même si la marque Sega figure sur la boîte grâce au programme de licence.

C'est le premier d'une petite sous-série centrée sur la Game Gear : GG Aleste II a suivi en 1993, et des décennies plus tard, M2, successeur de Compile Heart, a produit GG Aleste 3 comme un nouveau titre dans le style Game Gear, regroupé dans l'Aleste Collection de 2020 pour PS4 et Switch — cette même compilation qui a aussi été vendue en pack de vente au détail avec un appareil Game Gear Micro. C'est précisément ce merchandising ultérieur qui pollue aujourd'hui une simple recherche sur ce jeu, comme détaillé plus bas.

Quelle est cette édition de la cartouche japonaise, et quel est le vrai code ?

Voici la mise au point à faire. L'unique fiche de la Media Arts Database pour GG Aleste (M726876) indique comme plateforme SEGAマーク3 — Sega Mark III, la console 8 bits de 1985, pas la Game Gear — avec le code produit G-1352 et le code-barres 4974365143527. Ces deux identifiants existent bel et bien et appartiennent à une vraie cartouche : ils sont imprimés sur des exemplaires du jeu Sega Mark III de 1988, sobrement intitulé Aleste — une sortie différente de celle traitée dans cet article. La base de données a mélangé le titre de la suite Game Gear avec les données concrètes du jeu Mark III original. C'est le même type d'erreur que ce catalogue a déjà documenté dans les propres listes officielles de Sega (des lignes de plateforme qui rangent un titre tiers dans le mauvais dossier) ; ici, elle apparaît plutôt dans la base de données gouvernementale.

Le vrai code de la cartouche Game Gear est T-66017, et trois sources indépendantes s'accordent : la propre liste des éditeurs de logiciels tiers de Sega (la page des titres Game Gear édités par Compile, sans la marque Sega) indique GGアレスタ avec 発売元：コンパイル, code produit T-66017 ; la fiche produit de Suruga-ya liste directement 品番：T-66017 ; et la base de données matérielle de SMS Power!, une référence en anglais tenue indépendamment des deux sources japonaises, indique elle aussi T-66017 pour GG Aleste sur Game Gear. Utilisez T-66017, pas le numéro de la fiche de la Media Arts Database.

Quand est-il sorti, et pourquoi les sources se contredisent-elles ?

Trois sources, trois dates, toutes dans la même fenêtre de six semaines fin 1991 :

  • Liste des éditeurs tiers de Sega : 1991年12月29日
  • SMS Power! : 20 décembre 1991
  • Suruga-ya (les deux fiches pour cette cartouche) : 1991/11/29

Aucune des trois n'est confirmée par une seconde source indépendante, donc nous ne pouvons pas résoudre cela de la manière habituelle de ce catalogue — en privilégiant la date que partagent deux sources. Nous retenons la propre liste d'éditeurs tiers de Sega comme date principale, le 29 décembre 1991, parce que c'est le calendrier de sortie propre de l'éditeur répertorié, tout en signalant clairement que SMS Power! l'avance d'une semaine et demie et Suruga-ya d'un mois complet. Quiconque catalogue cette cartouche par ses propres moyens devrait traiter « fin 1991 » comme fiable, et le jour exact comme non résolu.

Combien coûtait-il au détail, et combien coûte-t-il aujourd'hui ?

La liste d'éditeurs tiers de Sega indique 4 800円 hors taxes. Le champ 定価 de Suruga-ya affiche ￥5 280 — exactement 4 800円 plus 10 % de taxe, les chiffres concordent donc une fois la taxe prise en compte.

Le 21 septembre 2026, Suruga-ya listait deux exemplaires du jeu de base : un exemplaire quasi neuf (美品), entre ￥48 100 et ￥405 600 selon l'état, avec un exemplaire de marketplace à partir de ￥26 620 ; et un exemplaire cartouche seule, sans boîte ni notice (箱説なし), à ￥26 400. Les deux chiffres dépassent largement les titres de stratégie Game Gear traités ailleurs dans ce catalogue, conforme à la réputation de GG Aleste chez les collectionneurs Game Gear comme l'un des shooters les plus difficiles à trouver complets.

Comment chercher dans chaque boutique face à la dilution par les noms de suites ?

Suruga-ya : le simple titre japonais GGアレスタ donne comme résultats : 8 (ce jeu : 2 ; GG Aleste II : 1 ; l'Aleste Collection de 2020 sur trois plateformes : 5), qui partagent assez du nom pour apparaître dans la même recherche. Le code produit sans trait d'union, T66017, est la voie propre : il renvoie exactement 1 fiche, et c'est ce jeu — mais il rate aussi la seconde fiche (sans boîte) que la recherche par titre capte, donc aucune des deux recherches n'est complète à elle seule. Utilisez d'abord le code, puis vérifiez la recherche par titre pour tout ce que le code aurait raté.

Buyee : le simple titre GGアレスタ renvoie 29 fiches, mais les véritables exemplaires de ce jeu précis — cartouches, sets complets — n'en représentent qu'une petite part ; le gros du reste, ce sont des fiches GG Aleste II, des produits dérivés GG Aleste 3 (panneaux acryliques, tapisseries murales, breloques), des DVD de stratégie pour les trois jeux, et du matériel indépendant. Ajouter le mot de plateforme (GGアレスタ ゲームギア) n'améliore pas vraiment les choses — les mêmes suites et produits dérivés continuent d'apparaître. Le code produit T66017 ne renvoie rien d'utile chez Buyee. Il n'y a pas ici de terme de recherche unique et propre ; il faut filtrer les résultats à la main, en cherchant les fiches indiquant clairement GGアレスタ sans II, 2 ni 3 accolé.

Pourquoi chercher sur Kataban ?

Parce que le bon code produit est précisément ce sur quoi aucune des grandes sources japonaises ne s'accorde proprement — la base de données gouvernementale se trompe même complètement, rattachée à une cartouche indépendante de 1988 — et une erreur ici signifie courir après la mauvaise fiche produit. Kataban associe le code corrigé au titre japonais, pour qu'une recherche ici ne risque pas d'atterrir accidentellement sur des fiches Sega Mark III.
