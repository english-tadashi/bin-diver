Histoire du développement de Castlevania, partie 4 : les codes portables auxquels il reste un suffixe de trop

2026-10-08

  • Game Boy Advance
  • Nintendo DS
  • Metroidvania
  • Années 2000
  • Konami
  • Castlevania

Dans la partie 3, le code produit PlayStation fonctionnait et le code produit Nintendo 64 renvoyait HTTP 404. L'ère portable échoue d'une troisième manière, et c'est celle qui coûte le plus de temps à l'acheteur : les codes sont là, ils sont corrects, et pourtant ils ne renvoient rien tels que le catalogue les stocke. Il suffit d'effacer les derniers caractères pour que la plupart se mettent à fonctionner. Les lignes Game Boy Advance et Nintendo DS sont aussi l'endroit où le catalogue écrit le nom de la série de trois façons différentes, et où l'année et le JAN d'une ligne désignent une édition différente de celle que désigne le code de cette même ligne.

  • Le catalogue Kataban contient 14 lignes Castlevania sur Game Boy Advance et Nintendo DS ; 5 seulement portent un code produit
  • Akatsuki no Menuetto est stocké sous AGB-A2CJ-JPN-1, qui renvoie HTTP 404 et zéro résultat ; AGB-A2CJ en renvoie deux
  • Sōgetsu no Jūjika est stocké sous NTR-ACVJ-JPN-2, qui renvoie HTTP 404 et zéro résultat ; NTR-ACVJ en renvoie quatre
  • Sōgetsu no Jūjika est sorti quatre fois au Japon — le 25 août 2005, puis trois éditions économiques en 2006, 2009 et 2010 — et les quatre lignes du catalogue portent exactement ces quatre années, le code et le JAN se trouvant sur celle de 2010
  • Le titre japonais de la ligne d'Akatsuki no Menuetto est écrit en caractères latins : Castlevania 暁月の円舞曲. Le chercher renvoie quatre annonces, et aucune n'est la cartouche Game Boy Advance
  • Les deux boutiques ne veulent pas la même recherche : Suruga-ya répond au code produit, et Buyee ne renvoie strictement rien pour AGB-A2CJ ni pour NTR-ACVJ — les mesures sont plus bas

Que contient le catalogue pour l'ère portable ?

Quatorze lignes portent un titre Castlevania sur Game Boy Advance ou Nintendo DS. Cinq d'entre elles portent un code produit : AGB-AAMJ-JPN-1 (Circle of the Moon), AGB-ACHJ-JPN-1 (Byakuya no Kyōsōkyoku), AGB-A2CJ-JPN-1 (Akatsuki no Menuetto), AGB-FADJ-JPN (le 悪魔城ドラキュラ de 2004 publié par Nintendo, vu dans la partie 3) et NTR-ACVJ-JPN-2 (Sōgetsu no Jūjika). Les neuf autres ont un champ code produit vide, parmi lesquelles Ubawareta Kokuin, les deux lignes Gallery of Labyrinth et trois des quatre lignes Sōgetsu no Jūjika.

Ce qui est vide, c'est le champ du catalogue, pas le jeu. Les deux boîtes portent un code imprimé : Ubawareta Kokuin porte NTR-YR9J-JPN, et Gallery of Labyrinth porte NTR-ACBJ-JPN accompagné d'un second numéro, RY024-J1, comme le montrent les photos ci-dessous.

Le nom de la série n'est pas écrit d'une seule façon dans ces lignes. Trois formes apparaissent dans le champ du titre japonais d'une même époque : 悪魔城ドラキュラ en kanji (Circle of the Moon, la sortie Nintendo de 2004, toutes les lignes DS), キャッスルヴァニア en katakana (les lignes sans code d'Akatsuki no Menuetto et de Byakuya no Kyōsōkyoku) et Castlevania en caractères latins (les lignes avec code de ces deux mêmes jeux). Le même jeu s'écrit de deux façons selon celle de ses deux lignes que l'on regarde : la ligne M720055 indique Castlevania 暁月の円舞曲 et la ligne M747166 indique キャッスルヴァニア -暁月の円舞曲-. Celle que l'on copie décide de ce que renvoie la recherche en boutique.

Pourquoi le code produit ne renvoie-t-il rien ?

Quatre des cinq codes stockés renvoient HTTP 404 et zéro résultat sur Suruga-ya tels qu'ils sont écrits : AGB-A2CJ-JPN-1, NTR-ACVJ-JPN-2, AGB-AAMJ-JPN-1 et AGB-FADJ-JPN. Couper le segment final de région et de numéro transforme les quatre en recherches qui fonctionnent. AGB-A2CJ renvoie deux annonces, NTR-ACVJ quatre, AGB-AAMJ une, AGB-FADJ une. Couper seulement une partie du suffixe ne suffit pas : AGB-A2CJ-JPN renvoie toujours HTTP 404 et zéro résultat. Le point de rupture est le trait d'union placé avant JPN.

Aucune source primaire sur le sens de ce segment final n'a été trouvée pour cet article. Nintendo ne publie pas le format, et les références de collectionneurs qui le décrivent ne sont pas de la documentation. Cet article n'affirme donc rien sur ce qu'encodent -JPN-1 et -JPN-2. La seule chose mesurée est celle-ci : l'index de recherche de la boutique répond à la racine et ne répond pas à la chaîne complète.

Le cinquième code fait exception, et cela mérite d'être dit avec précision plutôt qu'arrondi. AGB-ACHJ-JPN-1 renvoie HTTP 200 et deux annonces, toutes deux des rééditions économiques : キャッスルヴァニア ～白夜の協奏曲～ [コナミ ザ ベスト] et キャッスルヴァニア～白夜の協奏曲～ [廉価版] (箱説なし). Le AGB-ACHJ raccourci en renvoie quatre : ces deux-là plus キャッスルヴァニア～白夜の協奏曲～（美品） et キャッスルヴァニア～白夜の協奏曲～ (箱説なし). Le code complet n'est donc pas simplement cassé ici ; il est plus étroit. Quand il trouve quelque chose, il trouve les éditions tardives et laisse de côté les premières.

Où pointe chaque champ de la ligne d'Akatsuki no Menuetto ?

キャッスルヴァニア 〜暁月の円舞曲〜 est sorti sur Game Boy Advance au Japon le 8 mai 2003, publié par Konami, deux jours après la sortie nord-américaine du 6 mai 2003 et un jour avant la sortie européenne du 9 mai 2003.

Le catalogue le contient deux fois. La ligne M747166 porte le titre キャッスルヴァニア -暁月の円舞曲-, l'année 2003, aucun code produit et aucun JAN. La ligne M720055 porte le titre Castlevania 暁月の円舞曲, la plateforme ゲームボーイアドバンス, le code produit AGB-A2CJ-JPN-1, l'éditeur コナミ, l'année 2005 et le JAN 4988602126327. La ligne qui porte le code n'est pas celle qui porte l'année de sortie.

Les mesures disent jusqu'où vont les champs de la ligne de 2005. Chercher le JAN 4988602126327 renvoie deux annonces, toutes deux marquées [コナミ ザ ベスト] : キャッスルヴァニア ～暁月の円舞曲～ [コナミ ザ ベスト] et [外箱のみ] キャッスルヴァニア ～暁月の円舞曲～ [コナミ ザ ベスト]. Le JAN ne renvoie pas du tout l'annonce sans mention. Chercher le code raccourci AGB-A2CJ renvoie deux autres annonces : キャッスルヴァニア～暁月の円舞曲～ et キャッスルヴァニア ～暁月の円舞曲～ [コナミ ザ ベスト]. Sur une seule et même ligne, le JAN ne trouve donc que l'édition économique, et le code trouve l'économique et la précédente.

Une chose doit être dite avec précision : aucune des sources consultées pour cet article ne donne de date de sortie pour l'édition コナミ ザ ベスト de ce jeu. L'article de Wikipédia en japonais énumère la sortie Game Boy Advance, la sortie sur la console virtuelle Wii U et l'Advance Collection, et aucune édition économique. Ce qui est mesuré, c'est que le JAN de la ligne de 2005 ne renvoie que des annonces [コナミ ザ ベスト] et que l'année de cette ligne est 2005. Les deux concordent ; concorder n'est pas la même chose qu'avoir une source, et cet article ne transforme pas l'un en l'autre.

Une mention à lire avant d'acheter : [外箱のみ] signifie la boîte extérieure seule, sans cartouche. C'est l'une des deux annonces que renvoie le JAN, et elle porte le même JAN que l'exemplaire complet. Une recherche par JAN seule ne prévient pas que l'un de ses deux résultats n'est pas un jeu.

Que se passe-t-il si l'on colle le titre japonais tel quel depuis la ligne ?

Chercher Castlevania 暁月の円舞曲 sur Suruga-ya — le champ titre de la ligne M720055, copié à l'identique — renvoie HTTP 200 et quatre annonces. Aucune n'est la cartouche Game Boy Advance. Les quatre s'appellent Castlevania Advance Collection, sous les formes [通常版] et DELUXE EDITION.

Ces quatre annonces existent parce que la compilation existe en rayon. Castlevania Advance Collection est sortie le 24 septembre 2021 sur Nintendo Switch, PlayStation 4, Xbox One et PC en téléchargement, développée par M2 et publiée par Konami Digital Entertainment, et une version en boîte a suivi le 31 juillet 2025. Akatsuki no Menuetto fait partie des titres inclus. La recherche en caractères latins ne renvoie donc pas du bruit : elle renvoie un autre produit, actuel, qui porte légitimement le mot Castlevania dans son nom japonais.

Chercher la forme en katakana renvoie bien la cartouche. キャッスルヴァニア 暁月の円舞曲 renvoie huit annonces : les quatre Game Boy Advance (キャッスルヴァニア～暁月の円舞曲～, la réédition [コナミ ザ ベスト], un exemplaire (箱説なし) et le lot [外箱のみ]) et les quatre mêmes Advance Collection. En retirant complètement le nom de la série et en cherchant seulement 暁月の円舞曲, on obtient les huit mêmes.

C'est le même échec que celui que la partie 3 a consigné pour LEGEND OF CORNELL, dans un autre champ d'une autre ligne : le catalogue écrit un titre japonais en caractères latins, la boutique l'écrit en katakana, et une recherche construite en recopiant le catalogue tel quel renvoie soit rien, soit le mauvais produit. Ici elle renvoie quatre résultats, ce qui est le cas le pire — une recherche qui renvoie zéro annonce elle-même son échec, une qui renvoie quatre articles d'une autre machine ne le fait pas. ★Comme le sujet de cet épisode est la forme d'écriture elle-même, toutes les chaînes à coller en boutique restent ici en japonais d'origine : ne les transcrivez pas avant de chercher.

Et Sōgetsu no Jūjika sur DS ?

悪魔城ドラキュラ 蒼月の十字架 est sorti sur Nintendo DS au Japon le 25 août 2005, puis a été publié trois fois de plus au Japon : コナミ ザ・ベスト 廉価版 le 29 juin 2006, コナミ殿堂セレクション 廉価版 le 29 octobre 2009 et ベストセレクション 廉価版 le 9 décembre 2010. L'Europe l'a eu le 30 septembre 2005 et l'Amérique du Nord le 4 octobre 2005.

Le catalogue en contient quatre lignes, datées de 2005, 2006, 2009 et 2010 — une pour chacune de ces quatre sorties japonaises, dans l'ordre. Seule la ligne de 2010, M720996, porte un code produit (NTR-ACVJ-JPN-2) et le JAN 4988602156287. Les trois autres portent des JAN (4988602121568, 4988602129977, 4988602149067) et aucun code. L'unique ligne avec code de ce groupe est donc la dernière édition économique, cinq ans après la sortie du jeu, et non l'original de 2005. Les quatre écrivent le nom de la série en kanji.

L'exemplaire de la photo ci-dessous porte, en haut à droite de la jaquette, l'ancienne marque CERO 12才以上対象. CERO a remplacé ses catégories d'âge d'origine par de nouvelles pour les titres examinés à partir de mars 2006 : cette boîte a donc été classée avant ce changement. Il s'agit donc très probablement de la première édition du 25 août 2005, qui correspond à la ligne de 2005 sans code, même si l'on ne peut pas exclure, à partir de la seule boîte, une réédition économique imprimée avec l'ancienne marque.

Chercher NTR-ACVJ renvoie quatre annonces : 悪魔城ドラキュラ ～蒼月の十字架～, 悪魔城ドラキュラ ～蒼月の十字架～ (箱説なし), 悪魔城ドラキュラ ～蒼月の十字架～[コナミ ザ・ベスト] et 悪魔城ドラキュラ ～蒼月の十字架～[コナミ殿堂コレクション]. Chercher le titre 蒼月の十字架 en renvoie cinq : ces quatre plus 悪魔城ドラキュラ～蒼月の十字架～[廉価版]. Chercher 悪魔城ドラキュラ 蒼月の十字架 avec le nom de la série renvoie les cinq mêmes.

La cinquième annonce est précisément celle que le code n'atteint pas, et le JAN de cette même ligne n'atteint rien d'autre. Chercher 4988602156287 renvoie exactement une annonce : 悪魔城ドラキュラ～蒼月の十字架～[廉価版]. Sur la ligne M720996, le code renvoie donc quatre annonces, le JAN en renvoie une, et les deux ensembles ne se recoupent pas.

Les mentions d'édition de la boutique et les noms d'édition documentés ne sont pas non plus les mêmes chaînes. L'édition de 2009 est documentée sous le nom コナミ殿堂セレクション ; l'annonce de la boutique indique [コナミ殿堂コレクション]. Deux des quatre éditions documentées portent 廉価版 dans leur propre nom, tandis que la boutique n'utilise [廉価版] que comme mention d'une seule annonce. Faire correspondre une mention de boutique à une édition datée relève donc de la conjecture, et cet article ne s'y livre pas : ce qu'il rapporte, c'est quelle recherche renvoie quelle annonce.

(箱説なし) est la mention d'état à lire ici. Elle signifie que la boîte et la notice ne sont pas fournies — la cartouche seule. Elle apparaît aussi bien dans l'ensemble des résultats du code que dans celui du titre : aucune des deux recherches ne la filtre pour vous.

Quelle recherche faut-il donc utiliser ?

Ce sont des résultats mesurés, pas des suppositions. Suruga-ya a été mesuré avec des URL de recherche brutes ; Buyee a été mesuré dans un vrai navigateur sur des URL de recherche brutes, parce que Buyee répond à une requête en ligne de commande par un HTTP 202 et un corps vide.

Les deux boutiques n'acceptent pas la même recherche. Sur Suruga-ya, le code produit est l'instrument précis : AGB-A2CJ renvoie deux annonces et NTR-ACVJ quatre, toutes du bon jeu. Sur Buyee, ces deux mêmes codes ne renvoient rien du tout — la page se charge, et il n'y a dessus ni décompte ni grille de résultats. Ce à quoi Buyee répond, c'est le titre japonais suivi du nom de la machine : キャッスルヴァニア 暁月の円舞曲 ゲームボーイアドバンス renvoie 47 hits avec la cartouche en tête de liste, et 悪魔城ドラキュラ 蒼月の十字架 ニンテンドーDS en renvoie 91.

Pour Akatsuki no Menuetto sur Game Boy Advance : utilisez AGB-A2CJ sur Suruga-ya pour la cartouche dans l'une ou l'autre édition, ou キャッスルヴァニア 暁月の円舞曲 pour tout voir, y compris le lot qui n'est que la boîte. N'utilisez pas AGB-A2CJ-JPN-1 tel que le catalogue le stocke, et ne collez pas Castlevania 暁月の円舞曲 dans une boutique.

Pour Sōgetsu no Jūjika sur Nintendo DS : utilisez 悪魔城ドラキュラ 蒼月の十字架 pour voir les cinq annonces, ou NTR-ACVJ pour quatre d'entre elles. N'utilisez pas NTR-ACVJ-JPN-2.

La règle générale que l'ère portable ajoute à cette série tient en une seule retouche : quand un code du catalogue se termine par -JPN, -JPN-1 ou -JPN-2, coupez au trait d'union placé avant JPN et cherchez la racine — sur Suruga-ya. La partie 2 avait trouvé un code Super Famicom correct que la boutique n'indexe pas du tout, et la partie 3 a trouvé la même chose sur Nintendo 64. Voici le cas intermédiaire : le code est bien indexé, sous une forme plus courte que celle écrite sur la ligne.
